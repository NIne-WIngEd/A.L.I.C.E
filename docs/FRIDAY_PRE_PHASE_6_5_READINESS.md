**Authority:** `docs/ALICE_FRIDAY_FLAGSHIP_GOVERNANCE.md`

> [!IMPORTANT]
> Friday's independent repository already exists, but Phase 6.5 has not certified runtime readiness. Until the gate passes, Friday remains governance and repository foundation only.

## Completed before Phase 6.5

- independent Friday repository;
- protected `main`;
- signed repository history;
- product-family governance and parser;
- privacy and identity boundaries;
- governance CI;
- A.L.I.C.E.-first capability authority;
- private-state separation.

## Allowed before Phase 6.5

- governance and documentation;
- repository controls;
- product-family manifests and validation;
- synthetic governance and isolation-test scaffolding;
- maintenance;
- planning and productization for capabilities already eligible through A.L.I.C.E.;
- security fixes that do not add capability.

## Prohibited before Phase 6.5

- production runtime activation;
- real host enrollment or real host state;
- Friday-first capability implementation;
- Friday-first capability testing;
- A.L.I.C.E. private source or state;
- A.L.I.C.E. memories, personality state, credentials, adapters, weights, or private policies;
- production model packs;
- persistent real-user data;
- claims that Friday has passed Phase 6.5.

## Phase 6.5 unlock requirements

The readiness gate requires exact A.L.I.C.E. certification and Rayan approval covering independently versioned host-neutral contracts, product and host isolation, synthetic multi-host tests, migration and rollback, release-attestation enforcement, capability-precedent checks, absence of private cross-product coupling, and Friday build and dependency independence.

Phase 6.5 certifies readiness. It does not create the Friday repository.
