# Native joint source representations

The new `export_joint_source_features.py` builds the source representation needed by MFM's own lexical/reference/original-copy learner. It reexecutes the explicitly selected original J4/P1 or private J5/P2 source input, verifies the complete externally frozen native fields, original alignment and cache identities, and calls the frozen non-IT backbone once with `use_cache=False`. Its complete detached BF16 hidden states and native source fields are saved and physically checked through the existing safetensors mechanism. Gemma's language head and formation targets do not participate.

The production entry loads processor and weights locally from the same physically verified prepared clone. Complete source preflight precedes weight loading; output containment is resolved before allocation. The clone is checked before and after extraction. A supplied object is permitted only for explicit fixture mechanics, and production consumption refuses fixture banks by default. A source bank cannot grant corpus rights or target-author authority.

Diagnosis preserved two actual boundary failures: the original 38,564-token J5 overflow was refused after model loading, and a path alias created output within the read-only prepared clone. The new producer preserves this exact integer field through validation, backbone arguments, serialization and consumption. Current text values must be zero; this admits the observed text contract, without claiming native image/audio/video support. Historical P1/P2 ID/mask projections remain projections and must be joined to the separate complete feature receipt.
