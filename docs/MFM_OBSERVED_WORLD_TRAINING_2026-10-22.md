# Observed-world formation teaching

MFM must learn complete, grounded formation from a changing experience history:
what happened, what is merely reported, what remains uncertain, which episodes
and relationships matter, what a mission actually achieved, and what a later
correction or revocation changes. Rill adds a second connected teaching world
with nine chronological cuts. It is model-authored training material, not an
independent evaluation family or proof of transferable competence.

This work follows the full capability build plan and the checkpoint-10 diagnosis.
The current nine-case learner continues unchanged through update 26. Preparing
broader teaching is independent of that run: frozen Gemma source representations
do not depend on the owned decoder's weights or target labels. The 20-epoch S5
language foundation remains complete and is not replayed.

## Construction design

Use a new explicit observed-world material profile. Historical J6 and broader
profiles promise particular migrations, worlds and rosters; relabelling Rill as
one of those profiles would falsify its lineage. The new profile binds the actual
composition, world prefixes, permission and delivery boundaries, complete native
source observations, processor/runtime evidence and original authored targets.
Source validation precedes the first target read. FINAL target access remains
closed. Original failed attempts and corrected author drafts are retained.

The source profile admits original metadata and the complete native source
directly. Its frozen record already carries the joint alignment, native batch,
expected source/processor identities, split lineage and code bindings. Do not
manufacture a historical fifteen-file packet or duplicate these roles merely to
match an older container. The new trainer reader must check the same causal and
physical guarantees against these actual originals.

The authored case contains a four-field target. Corpus-v3 expects a six-field
standalone target with context and ordered source IDs. Save that exact shape
conversion separately, retain both FILE identities and bind its producer and
original author inputs. A corpus admission pass alone cannot bind reference or
copy choices: the trainer must also validate the complete observed pair and its
explicit original candidate and literal selections.

Extend the existing reference and original-copy dispatch at their schema
boundaries. Reuse their normative field responsibilities, reference markers,
original-byte occurrence alternatives and complete mixed-wire objective. No new
decoder, output repair, selected-token loss, inferred teacher choice, shortened
source or truncated target is part of this extension. The source feature profile
remains the existing `j6-source-only` exporter.

## Implementation and verification

1. The two observed-world pairing modules admit full source originals and bind
   complete authored targets to the observed native target geometry. Test the
   real nine-cut originals, exact reference candidate paths, source/target
   tampering, development handling and FINAL refusal before the author reader.
2. The existing reference and copy lowerers accept this distinct profile. Match
   all nine lowered decisions, ordinals and copy alternatives to the saved native
   geometry; retain historical-profile regression controls. These are material
   and lowering checks, not a learned-capability assessment.
3. Admit the real source bodies, rights, author input/output and explicit target
   conversions through unchanged corpus-v3. Preserve the original connected
   train family and separate diagnostic development originals. The new trainer
   metadata reader joins that authority to the source/pair and produces the
   complete original training operands before any model or feature load.
4. Obtain the complete frozen features from the separate Magnolia export. The
   observed maximum of 86,088 source tokens is a construction measurement, not
   demonstrated forward capacity. Preserve every original source position.
5. Select and implement the next data phase from actual checkpoint-26 behavior
   and the completed feature bank. Retain the earlier reading-room teaching when
   adding Rill, with the existing equal-world/cut/variant masses. Broader teaching
   is not conditional on pretending that old teaching fit establishes full MFM.

The next data phase requires an explicit checkpoint/interface transition. Adding
the profile changes the imported source closure; the old 104 literal interface

history and strict loader. A child transition must bind both closures, verify
the unchanged numerical model and parameter identities, and record optimizer

budget-only successor contract deliberately does not authorize new data.

The completed material contains 506,808 source positions, 17,052 canonical target

These results establish correct construction operands, not learned formation.

Trainer admission must join each opened source's identity to both the corpus
manifest and rights receipt. Matching source bytes alone cannot establish that
the rights record names that source. The corpus source family must equal the
composition's declared source family; source-author family remains a separate
lineage field. The explicit pair-construction result binds the standalone
conversion's actual producer file and per-case original references. It does not
replace reconstruction of the complete converted target's semantics.

The actual corrected corpus-author bridge passes for all nine cases. Thirteen
focused tests, four explicit provenance controls and eighteen historical trainer
regressions pass. The original nine-source preflight and native-choice checks
are retained; the final bridge run deliberately reuses that geometry evidence.
It does not repeat the full corrected source preflight or execute the new
processor lowerer, feature join, model or data-phase transition. Those actual
execution connections belong to the next construction package. Forty-one
historical functions, including the optimizer and checkpoint path, remain
structurally identical. No production source or checkpoint was changed.

The selected continuation and this material extension do not grant accepted
memory writes. Full MFM still needs native generated formation, useful consumer
behavior, broader and independently separated development, native media and the
accepted-memory → judgment/action → observed-outcome → governed-revision loop.

checks. TRACE157 records the actual completion and pending status of each step.
