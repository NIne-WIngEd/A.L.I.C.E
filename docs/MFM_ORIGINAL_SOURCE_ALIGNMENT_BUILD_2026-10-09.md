# Original-source alignment construction

The next build connects the separately supplied caller input to the existing source processor and to exact literal output. It implements a missing dependency of the selected full producer; it does not change the frozen E20 run, import a language head or claim learned selection/copying.

The existing caller inventory is independently frozen before teaching labels. Its original bytes, complete source order, registry and eligible typed candidates remain controlling. Source rendering escapes Unicode and literal media markers, while canonical output uses UTF-8 JSON. Source token IDs cannot therefore serve as original byte or output token identities.

## Implement now

Add a separately versioned text-source batch and alignment consumer alongside the unchanged v1.6 batch function. It calls that existing processor path, renders the exact same explicit template, obtains character offsets from the actual fast tokenizer, and requires equality of the complete actual IDs and attention mask. An external caller digest and an external processor binding are mandatory. Bind the complete serialized tokenizer backend, wrapper configuration, runtime versions, template and responsible source files; do not infer an original occurrence from a deduplicated source key.

Construct the reversible character-to-original-UTF8 map from exact bytes. Mark only observed source-body positions eligible; instructions, scoped context, source metadata, JSON delimiters and template text remain ineligible. Retain overlapping token offsets and partial JSON-escape coverage explicitly. A token may supply contextual support for a character without being a independently copyable token. Do not normalize or replace Unicode.

After that target-free input is frozen, a separate literal consumer receives an authored string. It records every exact original occurrence, the rendered source span, supporting eligible token positions, and that original literal's canonical UTF-8 JSON encoding. Lack of an exact occurrence remains a semantic-authoring case. It never turns paraphrases, context strings or a first matching mention into copy labels. Typed reference candidates and their digest remain separately bound; their selection is still a learned responsibility to build.

The first connected implementation covers text/code/structured evidence. Native media must refuse this text-only adapter explicitly. Next, build modality-specific maps from actual decoding/segmentation and processor replacement positions into original media locators, preserving each pending native responsibility. A caption or hash cannot replace sensory input. No text pass establishes native formation.
