# MFM V1 licensed-base direction

**Owner-local decision:** 2026-09-29. **Status:** architecture direction, not a
trained or qualified model. This applies to Fable V1 and A.L.I.C.E. MFM research.
The [native lineage decision](MFM_NATIVE_LINEAGE_DECISION_2026-09-29.md)
remains the long-term first-party foundation destination; its blanket ban on
third-party ancestry is superseded for the V1 route only.

## Lineage and product claim

V1 may import an exact, pinned, Apache-2.0-licensed **pretrained/base**
`google/gemma-4-12B` checkpoint into an owner-controlled artifact store.
Create an immutable byte-for-byte source snapshot, then a separate working
copy. Bind publisher, repository, exact revision, every file digest, model
configuration, processor/tokenizer, Apache license and upstream notices to the
working artifact. The previous `google/gemma-4-12B-it` instruction-tuned
trainer and all its fit/staging receipts remain historical research. Do not
remove its research guard or relabel its output as this new V1 path.

The working copy can be pruned, edited, continued, and specialized for an
evidence-bound formation objective. Preserve each transformation, parent
digest, data origin, objective, and capability/regression result. A copied or
modified tensor remains derived from the licensed source; pruning cannot
establish an exclusively first-party root. No model-size or inherited
architecture choice is itself a full-capability claim.

The common base contains no person's private life. FBM assembles separately
versioned user-specific learned components and governed memory from that
person's authorized evidence. Keep personal adapters, deltas, checkpoints,
optimizer states, retrieval indexes and backups in distinct instance custody.
Do not promote any user's learned parameters or source data into the shared
base. User control and the product's assignment/licensing of original personal
components must be specified in the Fable agreement; neither source-weight
ownership nor automatic copyright in AI-generated numeric weights is asserted.
The future first-party scratch-trained base must be replaceable through an
interface and independently requalified, not merely promised as completed.

## Behavior boundary

The base supplies general semantic and sensory representation, not canonical
memory authority, identity, personal voice, or final judgment authority.
MFM emits source-linked, uncertain proposals. Registered original evidence
and the independent deterministic Claim gate decide writes and revisions.
MFM needs separately initialized and trained formation-specific weights with
their own objective, versioned data and causal contribution. Editing or
fine-tuning Gemma alone and serving its free-form answers as the MFM is not
the V1 architecture. The base-only and base-fine-tune controls must lose to
the assembled formation specialist on held-out memory tasks and authority
boundaries; otherwise the claimed separate MFM has not been demonstrated.
Personal identity, judgment and conversational behavior require their own
learned stages and causal tests. No prompt, mask, prune, full-weight update or
finite benchmark proves that all pretrained behavioral priors were removed.

Qualify V1 on independently held-out people, source systems, generators,
modalities and time windows. Require no critical foreign-persona takeover,
false autobiographical memory, wrong-subject attribution, unsupported
certainty, deletion persistence or unauthorized write on the designated
adversarial suite. Test the contribution of each personal component by
removing or swapping it, and compare with the untouched shared base. Report
each critical failure and any remaining base influence; do not translate a
finite pass into a universal zero-influence claim. Grow training and the suite
when the full role contract fails. The existing 49,819 formation cases are
training-only and cannot serve as independent FINAL.

## Private-data boundary

Download, audit, pin and stage the complete base and its runtime **before**
opening private evidence. Load approved local tensor files with
`trust_remote_code=False`, no unsafe pickle loading, local-only mode, a
reviewed processor and dependency lock. Run personal inference and training
in a process with operating-system-enforced outbound network denial. Disable
telemetry and payload logs; inspect error reports, caches and exports. Test
the no-egress boundary with sensitive fixtures. Cloning weights alone does
not create this boundary. A local tensor forward pass cannot send data to
Google without an executable or network path, but no software stack can
promise zero leakage under every host compromise or implementation defect.

Any optional outbound feature model must get only the specifically authorized
minimum context. Ordinary cloud GPU training exposes data in use to the
compute operator unless a separately verified confidential-computing boundary
applies. Private Elaina or consumer data must not be placed on an untrusted
compute route. Per-user trained artifacts may memorize inputs and are private
data themselves; deletion, export and backup policy must cover them.

checkpoint: <https://ai.google.dev/gemma/docs/core/model_card_4>. Apache
permits commercial copying, modification and redistribution without a royalty
but requires its license and applicable notices, and does not grant Google
trademarks: <https://www.apache.org/licenses/LICENSE-2.0>. This is a
nonexclusive permission, not an assignment of the source or a guarantee that
no third party will ever raise a claim. Record artifact-level rights review
before distribution. Do not claim Google owns the independently made Fable
system or private evidence merely because licensed weights are included.

Before paid training, implement a **new** exact-base admission and local clone
receipt, secure processor/load path, provenance for every edit, privacy
boundary, user-specific separation and the independent behavioral gate.
Verify exact processor output and full backward/checkpoint/restart on the
actual intended allocation. The superseded `-it` CPU/GPU receipts do not
qualify this route. No V1 foundation copy, specialized MFM checkpoint,
independent FINAL or product qualification is claimed by this document.
