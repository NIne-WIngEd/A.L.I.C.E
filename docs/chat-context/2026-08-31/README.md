# A.L.I.C.E. Chat Context Archive

This directory lives on the dedicated non-canonical `alice-context` branch and exists so a future A.L.I.C.E. working chat can reconstruct the project without requiring the owner to re-upload long historical files.

## Start here

1. Read `CURRENT_STATE.md`.
2. Read `TERMINAL_OPERATING_PATTERN.md`.
3. Read `SOURCE_INDEX.md`.
4. Read `src/S02-memory-handoff.md` for the Stage G/G+ memory-architecture direction.
5. Read `src/S01-kaggle-handoff.md` for remote-compute operations.
6. Read `src/S10-terminal-023643.txt` for the newest continuation attempt, then `src/S09-terminal-004240.txt`.
7. Use the older normalized chat exports only when a decision, failure mode, or rationale is not already captured by newer evidence.
8. The exact MC10B v1.1.0 release is preserved as `mc10b/release-v1.1.0.zip`; directly readable scripts/audit artifacts are flattened under `mc10b/` and `mc10b/audit/`.

## Authority rule

This archive is context, not canonical authority. Current ratified repository files, executable validators, canonical Stage G artifacts, and current machine evidence win if they conflict with a prior chat transcript.

## Windows path-safety rule

Repository paths are intentionally flattened. Do not re-expand the MC10B release beneath deeply nested descriptive directories on Windows. `SOURCE_MANIFEST.json` maps short repository paths back to original names and paths.

## Security note

The repository is public. Live credentials are intentionally excluded. Never add API keys, PATs, passwords, private keys, or unredacted secrets.
