# Accepted audit direction and implementation boundaries

Authority: Rayan's explicit acceptance of Astra's audit and instruction to continue in this conversation on 6 September 2026. This document makes that acceptance durable. New numeric release thresholds are not invented here.

## Preserve the destination

ALICE is one continuing entity combining learned Elaina-derived personality, learned memory formation (AMFM), governed evidence and claims, Rayan understanding, relationship state, self-history, skills, goals and an executive. The executive reasoning model is replaceable; the entity's continuity must survive that replacement. Final deployed model choices remain empirical and are not the same as the proposal-generator or judge roster.

All 128 substantive owner-attested Elaina source records remain E0; enhanced wording does not make them synthetic. Learn interpretation, judgment and difficult or sharp supported traits, not just voice. Maintain independent judgment without silently replacing authenticity with generic soothing behavior. Personality synthesis is ambitious and may be large; finite historical evidence is not a permanent ceiling. Generated possibility or inferred personality is never new historical source-person evidence.

Keep source, host, relationship and self distinct. Revisable canonical personal facts belong in governed memory; learned weights can encode behavior and procedures but do not replace source authority, correction, lineage or rollback. Preserve the logical fabric, including event/claim time, identity, authority, projections, episodes, memory views, goals, skills, archive and training registry. Physical co-location is allowed only if full semantics survive.

## Accepted corrections to how we prove it

1. Tie each important requirement to a hypothesis, experiment, matched baseline, result and unresolved failure. Measure behavior and uncertainty resolved, not package count.
2. Treat reused public judge tasks as development/calibration. Freeze prospective, independent, source-family-aware evaluation before its answers are used for tuning. MC8 remains sealed.
3. Compile the effective judge contract from named source policy and ratified amendments. Keep scientific gates, runtime readiness, schema validity, semantic calibration, acceptance and promotion distinct.
4. Preserve all valid results. Read existing v186 output before deciding on any rerun or judge change. Consolidate future operational code around testable contracts instead of extending a chain of string patches.
5. Follow the seven experiments in EXPERIMENT_LEDGER.json. A small decisive experiment must use its intended semantic architecture; it is not permission for disposable cognition.
