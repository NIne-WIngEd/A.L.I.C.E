## Execution

Save this ZIP and `Start-ALICEAstraQwenQualificationV105.ps1` beside each other in
Downloads. Run the launcher from the existing PowerShell environment. Anaconda
is preferred. The native SSH key is used without path conversion. Remote paths
remain POSIX paths.

1. Verify the ZIP, manifest, Python compilation and offline boundary tests.
2. Verify the observed local a2 state, both exact remote parent origins and their
   terminal scheduler identities. Verify the installed publisher, SSH wrapper
   and the retained successful repair receipts.
3. Verify TLS access and reuse the exact a2 model manifest. Submit one allocation:
   Magnolia `node/normal`, 20 CPUs, 48 GiB exclusive, six hours, no GPU.
4. Publish initial telemetry. Prepare the pinned runtime/model. Run the original
   128-token public throughput probe. The original worst-case budget gate must
   pass before any of the 16 calibration requests begins.
5. Collect original responses and runtime evidence. Rebuild the result locally
   and publish the permitted summary to `alice-context`.

The worker, runtime policy, prompt, scientific authority and all 17 request
hashes are preserved. There is one request per task. A consumed intent cannot
be retried. No launcher creates another execution ID or falls back to Kaggle.
Rerunning this same launcher reattaches to a known submission or retries its
collection/publication. An unresolved submission intent stops rather than
submitting another job.

Return `RESULT_ZIP` and the transcript. A pre-submission or transport stop also
prints `STOP_ZIP` with the available raw RPC output. If result verification stops
after a valid transfer, `RAW_RESULT_ZIP` preserves those bytes for review.

The workload records the installed helper identity. Publisher stdout/stderr and
raw Git command journals are included in the returned result. Journal export is
restricted to this execution's snapshot IDs and excludes indexes, caches and
unrelated runs. The original private journals remain on Magnolia.

The CPU runtime and throughput are still unobserved. Offline tests use synthetic
responses and local Git fixtures. They do not qualify Qwen. Actual a3 submission,
native launcher execution and model inference remain pending until the owner
runs this package and returns its receipts.

lineage checks. The new distribution hash identifies the infrastructure package;
