## Binding rule

A.L.I.C.E. is not an infrastructure benchmark. The live selected architecture is
the default. Validation exists to protect capability and real implementation
decisions, not to create work.

The earlier Stage G exhaustive interpretation requiring every named backend,
same-role all-pairs, every candidate substitution and broad combinatorial
coverage is superseded.

## Selected path

- PostgreSQL: separate Experience/Event and bitemporal Claim contracts.
- Content-addressed local object/file storage: raw evidence, datasets, weights,
  manifests, exports and backups.
- Neo4j: A.L.I.C.E. full-profile cognitive graph accelerator, derived only.
- Qdrant: semantic/multimodal accelerator, derived only.
- Direct source-native retrieval: filesystem, SQL/FTS, metadata, APIs and live
  systems of record.
- Context Planner: chooses exact/source-native, claim, graph, temporal, vector,
  episode and live-source paths.
- Temporal: durable long-running/distributed A.L.I.C.E. workflows where needed.
- In-process workspace first; Valkey only when shared/distributed ephemeral state
  becomes useful.
- PyTorch + Accelerate; current DDP route; FSDP/offload only from measured need;
  Slurm on cluster.
- Content-addressed artifact manifests first; MLflow optional.
- vLLM only for suitable large-model serving profiles.

Fable v1 uses a lighter local physical profile while preserving logical
capabilities. Capability parity does not mean backend/daemon parity.

## Critical path

1. Finish current N0 whole-step CUDA gradient/optimizer/resume proof, measure real
   training memory, choose hardware once, and train.
2. In parallel build MFM gold/context/formation capability and FBM real builder
   input-target-outcome cases.
3. N1/N2/N3 + MFM + host/relationship/self development.
4. Integrate complete Stage G on selected stack.
5. Stage H canary -> Stage I cutover -> Stage J compatibility/fallback acceptance:
   final Phase 2 replacement.
6. Generalize successful A.L.I.C.E. construction into FBM.
7. Ship Fable v1 when the personal loop works for a fresh user.

AirLLM frozen-base adapter training is not a substitute for current native N0
training.

## Challenger rule

Reopen infrastructure only for a concrete capability/fidelity, correctness,
scale, latency, reliability, privacy, deletion/recovery, packaging, licensing or
cost problem, or strong frontier evidence the selected path cannot express.

If a validation result would not change the next implementation decision, stop
validating and return to A.L.I.C.E. work.
