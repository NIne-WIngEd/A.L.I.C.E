# ADR-003 — Adopt Roadmap 2.0 Cognitive Architecture

**Status:** Superseded
**Date:** July 27, 2026
**Decision owner:** MK Rayan

## Supersession note

This decision records the first approved cognitive-system expansion. It was superseded the same day by ADR-004 through ADR-007, which replaced preservation-first governance, made Phases 1–4 migratable released baselines, added project-wide capability profiles, created the host-neutral Personal Cognitive Kernel and consumer product track, and established host-selected identity with full destination capability parity. The original text remains below for decision-history continuity.

## Context

The original roadmap described a capable personal assistant but did not fully represent the approved long-term goals: continuous selective learning, autonomous memory formation, a predictive model of Rayan, stable independent judgment, self-generated code and skills, evaluated self-training, world and causal models, universal perception/action, scientific discovery, embodiment, and long-term research into currently unsolved capabilities.

Repeated top-level replanning would disrupt active engineering, particularly Phase 4.5.

## Decision

Adopt Roadmap 2.0 with frozen Phases 0–15; define a permanent model-independent cognitive architecture; add capability, lifelong-learning, autonomy, and research-frontier documents; expand but do not replace the existing Constitution and policies; and preserve Phase 4 as read-only.

## Consequences

- Completed Phases 0–3 remain closed.
- Phase 4.5 continues without automatic memory or training.
- Phase 5 begins the Experience Ledger and evaluation substrate.
- Future ideas route into the catalog, architecture, subphases, ADRs, experiments, or frontier register.
- Powerful capabilities remain legitimate goals but require verification proportional to consequence.
- Unsolved capabilities remain explicit research programs rather than disappearing from scope.

## Rejected alternatives

- Reopen and redesign completed phases: rejected because their interfaces already support the new direction.
- Add continual learning directly to Phase 4: rejected because it mixes public retrieval with memory authority.
- Fine-tune one personal model immediately: rejected because memory, outcomes, evaluation, and curated data must precede durable parametric adaptation.
- Keep changing the top-level roadmap for every new capability: rejected in favor of the freeze policy.
