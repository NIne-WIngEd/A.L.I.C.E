# ADR-004 — Replace Safety-First Governance with Ambition-First Authority

**Status:** Proposed
**Date:** July 27, 2026

## Decision

Replace the existing Constitution and layered amendment with Constitution 1.0.0. Adopt a minimal authority kernel and make all other governance constraints evolvable, reviewable, and capability-preserving.

## Rationale

The previous framework could block continuous learning, autonomous code promotion, broad personal modeling, weight adaptation, and self-modification through default-deny and least-agency assumptions. The new framework treats containment and evaluation as mechanisms for enabling capability.

## Consequences

- Phases 0–3 remain technically complete.
- Runtime permission mappings will require a later migration from permission levels to mission/autonomy classes.
- Phase 4.5 may resume after documentation merge; no Phase 4 capability is broadened by documentation alone.
- Future self-improvement can earn automatic production authority.
- Only the minimal authority kernel remains constitutionally protected from autonomous activation.
