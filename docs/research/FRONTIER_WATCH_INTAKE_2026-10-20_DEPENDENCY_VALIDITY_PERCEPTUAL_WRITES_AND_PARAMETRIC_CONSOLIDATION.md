## 1. Tether / Fallout — upstream reasons outlive a cached valid verdict
**Class:** direct future capability/qualification improvement; no demonstrated current implementation defect.
**Primary:** *Memories That Outlive Their Reasons: Dependency-Tethered Memory for Tool-Using LLM Agents*, arXiv:2610.25123v1, submitted October 18; https://arxiv.org/html/2610.25123v1 .

**Method:** at verdict-writing time capture exact object-version `derived_from` edges; at use time traverse entire support graph, demote to UNKNOWN/null any apparently passing verdict whose ancestor failed or was version-replaced. No replacement Claim Authority is introduced. Fallout simulates tool checks/publish decisions over software, research, and manufacturing dependency DAGs with independently computed validity. In the main same-session relation setting, Tether's affected unsafe-publication rate is ~0.3–0.5%, versus ~61.9% for an edge-free fact memory, at ~0.63 checks per candidate vs 1 for always-verify. This reduces checks by ~37%. Wrong verdict persistence occurs even when individual observations were originally true. Source-relative scope matters: when relations are stated in earlier/later sessions, edge recall falls from 1.0 to .840/.658 and unsafe publication increases to 9.4%/22.1%. Missing edges, not score calibration, are the failure. A false added edge triggers extra checks, not authority rejection.

**Already covered:** bitemporal Claim Authority; append-only Experience evidence; graph/influence/deletion lineage; Mission/dependency state; source-native versioning; reversible projections; independent action verification. **New:** explicit transitive *eligibility of a previously accepted verdict at action time* when a nonlocal support premise has changed, and a cheap distance-stratified failure discriminator. Deletion lineage alone does not guarantee ordinary (non-deletion) dependency invalidation.

**Action:** when an actual stored-verdict→Mission-action path exists, verify one case: a supported parent version is later revoked outside the active context; a prior derived success remains historical evidence but is not action-eligible without re-check. Test one cross-session dependency extraction case and a missing-edge fail-closed path. Do not infer every graph association is a logical support edge; only source-evidenced, version-scoped dependency edges may trigger authority checks. No backend tournament. Validation is future unless active action admission currently misuses cached verdicts.

**Costs/risks/evidence:** writer must extract/store exact versioned edges and read-time graph reachability increases work; much cheaper than many re-check tools when edge coverage is high. Synthetic deterministic objects, short histories, writer behavior, not real human/ambiguous premises; conservative higher-version trigger can induce perpetual rechecks. Subject/host/agent identity, permissions, custody, revocation lineage and rollback must constrain every support edge. Read-time invalidation demotes use, never rewrites an original Experience as false.

## 2. BetaMem — coupled perceptual/source-grounded writes and repairable memory policy
**Class:** future challenger / direct future perceptual formation improvement.
**Primary:** *BetaMem: Learning to Remember a Changing World for Embodied Agents*, arXiv:2610.26554v1, submitted October 19; https://arxiv.org/pdf/2610.26554 .

**Method:** six linked layers for working, spatial, entity, episodic, experiential and procedural state; observation time, validity interval and revision time; retain source RGB/depth/audio observations and source-availability metadata. SFT then GRPO (eight samples per window) learns atomic writes with (a) executable operation/schema checks and (b) source-grounded semantic coverage checks. Proposes diagnosed local changes to write/retention/retrieval/freshness policies subject to independently replayed version promotion. Treat original observation as a lead; reobserve for present-state assertion.

**Evidence and ablations:** trained Qwen3.5-9B write-contract compliance improves from 50.9% to 86.2% on 20 in-house clips, generated output tokens per stored action from 224 to 118 (47.3% reduction). M3-Bench-robot QA 48.08%; removing linked source utterances reduces to 38.61% (-9.47 pp); removing visual identity discovery/confirmation to 42.69% (-5.39 pp); visual–event consistency to 42.31% (-5.77 pp). LoCoMo 92.08% only on four non-adversarial categories; OpenEQA 72.6% LLM-Match with 24 frames; EgoLifeQA A1-JAKE 62.4%; comparisons vary readers, modality budgets, and judges. The independent replay policy-repair cycle is specified, but do not claim a controlled end-to-end policy-improvement ablation absent from those result tables.

**Already covered:** perceptual source-native evidence, full multimodal+graph+episode+procedural planes, MFM proposals before deterministic authority, event-vs-current Claim temporal scopes, independent verified Mission outcomes, controlled model/contract promotion. **Genuinely new:** paired learned memory-write *tool validity* and *content/source support* objective with source-linked multimedia ablations, plus explicit independently replayable memory policy corrections. A six-layer taxonomy and 9B model are study choices, not Fable ceilings.

**Action:** future MFM/perceptual evaluation should separately record (1) valid write operations (2) verified source support and omission (3) downstream retrieval and current-state confirmation. A learned write remains only a proposal; independent Claim Authority/subject identity/consent/admissibility, deletion/influence invalidation, rollback and preserved originals are mandatory. Runtime costs include SFT/GRPO inference/training, visual source storage and repeated sensor reads, independent replay; privacy/access and source retention cannot be optimized out by budget.

## 3. Cortex — prospective rehearsal from external context into parametric state
**Class:** future challenger for parametric personal-memory consolidation; not a training recipe change today.
**Primary:** *Cortex: Consolidating Context into Parametric Memory*, arXiv:2610.20399v1, submitted October 14; newly surfaced October 20; https://arxiv.org/pdf/2610.20399 .

**Method:** sample prospective future queries using source context; compute teacher answers and output/hidden states from the pre-update model with that context; train newly introduced synaptic low-rank changes or structural FFN channels to reproduce context-conditioned behavior *without* context at inference. Freeze earlier trained parameters, allow mergeable adapters; compare consolidation rate (fraction of context-induced gain retained without context) and retain rate (performance on unrelated tasks). Sequential protocol evaluates still-valid changes after each step.

**Evidence:** testbed of five task families, 4B–120B text/MoE/multimodal backbones and single/batch/sequential conditions. On 50 sequential edits to a 14B model, Structural recovers 88.9% of gain while retaining 99.8% non-target performance. Detailed ablations vary number of rehearsal examples, update location, historical replay, hidden-state alignment, answer source and per-edit capacity. Smallest capacity in one measured sweep outperforms larger settings (88.9 vs 84.3% CR across Structural endpoints), so added parameters do not guarantee better consolidation. Strong results are selected benchmark settings, not verified personal lifelong learning or deletion. Model execution costs include teacher-with-context queries, rehearsal generation, KL/hidden-state fitting and additional modules per edit.

**Already covered:** Fable parametric personal memory, MRM scheduling external/parametric/activation, governed model and dataset generations and promotion, lineage, corrections, rollback and cross-layer deletion. **New:** explicit controllable external-context→weight internalization objective using *prospective query* rehearsal and paired retain tests. The work offers a plausible challenger only once a real eligible personal-model consolidation need exists; it is not permission to put host data in shared weights or infer that transferred outputs are facts.

**Action:** log as future controlled consolidation comparison, not today's MFM step. Context/teacher answers can be wrong or unauthorized; source hashes, speaker/host/self boundaries, dataset consent, validity/version, revocation and independently verified promotion must bind each learned generation. On correction/deletion, either rebuild/retrain/verified unlearn or retire the affected model generation; a merge is not an irreversible authority migration. Retention should not preserve a revoked belief.

## 4. ScopeMem — targeted revision must count harms as well as repairs
**Class:** future challenger for Cognitive Workspace/activation-conditioned native judgment; no present deployment action.
**Primary:** *ScopeMem: Latent Memory That Learns Where to Revise Frozen GUI Agents*, arXiv:2610.26503v1, submitted October 19; https://arxiv.org/html/2610.26503v1 .

**Method:** frozen VLM acts first; a 10.5M-parameter encoder sees the first action, confidence, task, short history and summary, then supplies activation prefix for second pass. CE trains corrections; additional scoped distillation preserves the original actor distribution *on examples where first decision was correct*. Without scope, cross-entropy prefixes revise many already correct decisions. Main controlled 1,463-step ablation: 584 originally wrong, 879 originally correct; scoped version repairs 254 errors while harming 49 correct cases (5.6% of originally correct), vs first-opinion CE repairs 243 while harming 67. Net correct-step gains of 14.01 vs 12.03 pp (paired effect 1.98 pp, 95% CI .53–3.44). Three GUI benchmarks and repeated 3 seeds; history-only conditioned encoder has weaker/uncertain contribution (scoped-first minus scoped-history interval includes zero). Different from learning factual autobiographical memory.

**Already covered:** native judgment gate, workspace projections, replaceable feature agents, provenance and provider independence, governed personal-model evolution. **New:** paired repair/harm measures and scoped preservation around the *initial correct native decision* when learning dynamic activation-based correction. This is a narrower capability than full personal learning.

**Action:** if learned activation/judgment-revision enters qualification, track originally-correct-to-wrong changes by host/person/mission and by corrected/revoked context rather than only total accuracy. A first-pass + second-pass doubles actor inference passes plus encoder. Prefix must remain nonauthoritative and have source-gated, deletion-aware lineage. No current GUI integration.

## 5. TokenWorth — learning memory value under joint use budgets
**Class:** future MRM policy challenger; narrower corroboration of Causal Memory Policy, MemComposer, and memory-use calibration rather than a new architecture requirement.
**Primary:** *Remembering Has a Price: Learning Memory Worth under Resource Constraints*, arXiv:2610.26453v1, submitted October 19; https://arxiv.org/html/2610.26453v1 .

**Method/evidence:** linear memory-value scorer plus RFM/AGOP residual updater gets execution reward and manages small retained bank and query activation under jointly fixed generation, tool-round and memory budgets. LifelongAgentBench DB/OS/KG using local Qwen2.5-14B and API DeepSeek-V4-Flash: on local DB success 65.0% vs best listed RAG 33.0%; output tokens vs no-memory reduced 9.3%, 51.5%, 18.7% local on DB/OS/KG, counting auxiliary model output tokens. Ablation: linear only 64.2%, linear + fixed residual 63.0%, adaptive feature residual 65.0%. Authors explicitly state selected-memory feedback does **not** identify causal contribution; tested only one stringent resource budget, not arbitrary scaling.

**Already covered/new:** MRM retention and activation and calibrated memory value already planned; the measurable two-timescale residual scoring under a joint output/action cap is a candidate learned execution scheduler, not an argument for shrinking the Fable memory fabric. Unknown utility is not low utility. Personal source privacy, legal retention and corrections prevail over the utility score.

**Action:** only test if actual bounded MRM workload has demonstrable output/time/resource deficit and a policy choice depends on it. Never permanently erase canonical evidence on sparse reward; bound cheap activation/index retention choices instead.
