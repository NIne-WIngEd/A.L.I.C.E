## New findings (all originally submitted October 23, surfaced by October 26)

### 1. MemCryst — reciprocal episodic memory / procedural skill learning with outcome-specific use adaptation

**Primary:** [Lifelong Context Adaptation through Bidirectional Memory–Skill Learning](https://arxiv.org/html/2610.32295v1), arXiv:2610.32295, Xu and Wang, **October 23**. **Classification:** **future challenger / direct future cognitive capability improvement** for procedural learning, Lifecycle Curator and Memory Resource Manager, **not current MFM repair**.

**Method and novelty:** Frozen actor; store chronological episodes, source-linked typed facts, and versioned parameterized textual skills with applicability guards. Recurring episodes are clustered and mined into skill candidates, independently audited in a fresh context. Skills guide actions whose independently observed outcomes create fresh episodes that can revise the same skill. Independently of **content update**, each outcome changes future retrieval **influence** only for facts and skills actually presented to the actor: fact exposure and success statistics, skill utility. Critically, failure adjusts *use* without rewriting a fact as false. The authors explicitly say an assigned task outcome is **not** individual causal attribution or epistemic confidence. Distinct from simply coupling skill and memory stores, from outcome-independent relevance, or from rewriting failure-derived guidance every turn.

**Evidence/ablations:** Ten benchmark/task settings in five domains; top compared result in 7/10; reported weighted overall 52.26% vs SimpleMem 39.92% under authors' aggregate. ALFWorld 600 online tasks: **63.17%** joint serving vs **59.83%** memory-only vs **50.50%** skill-only. Frozen skills but continued serving reaches 62.00%, so revisions add **1.17 pp**. Both outcome-return channels beat neither by **3.50 pp**; 2×2 return interaction +**5.33 pp**. A shared domain-scoped store yields **44.50%** versus 28.30% for stateless on 1,018 interleaved scored tasks, but remains below separate specialist mean **48.50%**. On a *frozen* 100-task ALFWorld control, relevant record selection achieves 75% vs 58% random, and replacing skill text with episodes yields 72%; skills inject ~62% fewer tokens, not a clean accuracy win over episodic context. Code benchmarks are mixed: MemCryst underperforms ReAct on MBPP. Causal contribution of one exposure is *not identified*; adaptation with inaccurate rewards untested, new-domain transfer unproven.

**A.L.I.C.E. coverage vs new:** Experience Ledger, Mission outcomes, governed procedural models, episodic/Claim separation, source lineage, FRESH/RIPPLE diagnosis and MRM already express all planes. New experimental control is **reciprocal skill→behavior→experience→skill** with *separately measured* content-vs-activation adjustment and joint memory/skill ablations. At future operational Mission+Curator junction, independently observe outcomes and compare learned procedure revisions and correct future retrieval on one recurrent task, a changing environmental precondition and a conflicting outcome. Must not treat outcome-derived utility as factual truth or permission.

**Governance, costs, action:** Each skill and its use statistics bind supporting episode/source IDs, subject/scope, version, outcome verification, identity ownership and correction/deletion ancestry. Explicit revocation must invalidate served activation and contaminated lessons/replayed outcomes; retrospective propagated influence cannot reintroduce a revoked procedure. Keep unselected/low-utility source evidence, permit rollback and rebuild. Costs: storage for episode+facts+skill generations; skill synthesis/audit LM calls; retrieval/context tokens each episode; ongoing outcome monitoring. **Research note only**, no new database, training change or extra benchmark.

### 2. ActionRAG — query-local associative graph *reevaluation* over entity **and triple** seeds

**Primary:** [ActionRAG: Evidence-Refining Graph Diffusion for Long-Term Memory in LLM Agents](https://arxiv.org/html/2610.32752v1), arXiv:2610.32752, Mahla and Vandrangi, **October 23**. **Classification:** **future challenger** for engine-independent associative graph compute / Retrieval Orchestrator.

**Method/novelty:** Resolve schema labels and ambiguous entity aliases cautiously when indexing; carry source provenance through relation summaries. Query encodes entity seeds **and predicate/triple seeds**; builds a bounded local neighborhood and applies receiver-normalized diffusion with direct-seed protection, hub penalties, and optional bridge-triple materialization. Key delta beyond flat vector search, PPR-only entity activation, and static graph traversal is **local path support can rerank initially retrieved candidate triples while preserving explicit source seeds**, without requiring an LLM entity extraction call on each query.

**Evidence/ablations:** MemoryAgentBench 8 deterministic-scoring columns, mean **55.1**, +**5.4 points** vs strongest listed retrieval baseline HippoRAG-v2, lead on six. Reconciled indexing plus diffusion 55.1 vs **45.5** on raw exact-match graph and **48.9** with summary-only without full reconciliation; base no-diffusion on reconciled graph **45.0**. Counterevidence: MH-DocQA 63 vs HippoRAG-v2 66, Detective QA 46.7 vs 57.7. Single-column MCC parameter sweeps can *outperform* default (default 82.0, alpha=.85 yields 84.8; omitting materialization 83.4), so default not universally optimal. EventQA source growth 409→2,948 graph nodes decreases score **73.2→69.0** despite near-stable context tokens and increases measured retrieval p99 **5,811→7,664ms** in the growth study. The much smaller cited **440.7ms** is a *sum of separately measured retrieval components* on another consumer Apple Silicon profile, not full end-to-end p99. Quoted synthesis under $0.001/query excludes graph construction, storage and embedding.

**A.L.I.C.E. coverage vs new:** Full Cognitive Multi-Graph, Qdrant, exact/source-native retrieval, graph associations, identity/temporal/Claim semantics are selected already. The new *candidate* is a query-local associative activation/reranker that might improve multi-hop relation misses. Do **not** add a hypergraph backend or replace LadybugDB/NebulaGraph/XTDB. Graph similarity is relevance, not evidence authority; an entity match is not identity adjudication; a superseded fact must retain valid-time and rejection status. On a future *observed* relational multi-hop miss, compare this local reranking only to current retrieval with exact supported-source coverage and total p95/p99/compute/memory. Deletion and rollback must invalidate derived graph, diffusion scores and any cached working context. **No work now.**

### 3. Beyond Gain — absence of skill benefit does not establish internalization

**Primary:** [Beyond Gain: Measuring Skill Internalization for Agent Skill Retirement](https://arxiv.org/html/2610.32322v1), arXiv:2610.32322, Wang et al., **October 23**. **Classification:** **future challenger** for skill/activation resource governance and evidence-aware retirement; clear negative control against unsafe pruning.

**Method/novelty:** The common aided-minus-unaided skill-gain score is near zero both if **the model already can do the task** and if **neither model nor skill can do it** ("uncovered"). Generate executable tasks from a skill with a different model family; run target without the skill; score only capability-dependent rubric items; high unaided score qualifies for an internalization declaration only if a witness model gains from the skill on the same task (task relevance gate). Target verdict is **per model**, not a universal library retire decision. A second task adds between-task reliability and threshold-near adaptive sampling. Neither repeated single-task runs nor Shapley/LOO on one skill removes the zero-vs-zero ambiguity.

**Evidence/ablations:** Release includes **1,251 skills** with four model evaluations; witness gate admits 844/1,165 tasks and only **52.6%** of tasks with high unaided scores, exposing easy-task false positives. One published band rule retires **57.5% of uncovered skills** (95% bootstrap 46.2–68.7) on their one-task reduction; restoring its aided-success gate can avoid most error. On 124 two-task skills, unaided-level verdict is more repeatable (κ **0.42** vs **0.23** gain-band) but still imperfect. At equal three-run measurement, 3 distinct tasks misclassify **11.4%**, vs three runs on one task **16.1%**. On SkillsBench, 28/31 band retirements are based on probes without any fully passing run. Caveat: finite synthetic skill tasks and judge-generated rubrics, applicability to continuously revised personal skills untested; a skill can be redundant for one model/task and important for another.

**A.L.I.C.E. coverage vs new:** Fable does not have an artificial skill count or competence ceiling; canonical procedural evidence, source lineage and selective memory planes already protect against naive hard deletion. The new direct metric is separate **uncovered vs demonstrated internalization**, useful before routing, offloading or deactivating a learned procedure for a particular model generation. The paper's word “retire” must be interpreted as **model/version-scoped activation/placement decision**, not deleting authorized evidence, canonical skills or training lineage. Require no-loss checks for changed host conditions, permissions, subject identity, corrected/deleted influences and older model rollback. Measured cost: many held-out tool executions and external rubric/witness inference; therefore run only when a real skill-library/serving-resource bottleneck exists. **No action now.**

### 4. CauProphet — transportable conditional causal models with active alternative-explanation tests

**Primary:** [CauProphet: Teaching Agents to Develop Causal Cognition like Humans](https://arxiv.org/html/2610.32477v1), arXiv:2610.32477, **October 23**. **Classification:** **future challenger** for causal/world state, Mission planning and outcome-based revision.

**Method/novelty:** Separate durable **Causal Cognition** from task-local, revisable **Causal Belief**. Retained relations carry conditions, time scale, supportive/contradictory observations, text mechanism, and open questions. Map factors into current task variables; investigate competing explanations with a Causal Scout; revise applicability and confidence from outcomes; project changes back as separate conditional hypotheses, retaining old versions. Approximate Bayesian update sums signed log-evidence weights, with *conditional independence of observations* as an explicit assumption. This is a candidate **causal learning/reuse protocol** within existing causal graph and Experience, not evidence that causality can be asserted from correlation.

**Evidence/limitations:** Six-period chronological finance research on AlphaBench, held-out return-rank correlation mean (×100) **5.149** vs ReAct + text memory **4.106** (+25.4% relative; very small absolute values). 24 FutureSim forecasting questions (195 question-day samples): pre-resolution top-1 **28.6% vs 21.3%** for ReAct, Brier skill 0.080 vs 0.049; final-day Brier **0.085 vs ReAct 0.092**, so not unconditionally better. Three known structural causal models (800 observations each) and simulated intervention games favor method, but small task and short study horizons. Authors acknowledge insufficient observations cause reliance on model priors. Tool calls for causal discovery, repeated experiments, storage/versioned explanations, potential leakage from correlated "independent" evidence raise runtime and false-confidence costs.

**A.L.I.C.E. coverage vs new:** Existing causal/social/world models, bitemporal Claims, source/subject separation, Mission Graph, Tether dependency validity and outcome ledger can express it. The experimental candidate is *reuse across contexts subject to explicit applicability conditions* plus active falsification and retained prior revisions. Causal analysis remains uncertain, must retain original evidence and distinguish action observed vs model-predicted effects; no reward-driven promotion to true Claim or auto-authority. Future targeted test only when a real Mission causal-transfer failure arises, comparing action outcome, source support, uncertainty and correction/rollback. **No current change.**

### 5. HarnessMM — guarded execution of already-resolved decisions without repeated model inference

**Primary:** [HarnessMM: Recursive Self-Improvement for Harness Token Efficiency](https://arxiv.org/html/2610.32813), arXiv:2610.32813, **October 23**. **Classification:** **conditional future challenger** for Mission/harness serving cost only when measured expensive repeated *same-decision* calls.

**Method and ablations:** Capture tool-derived action as an Executable Decision Graph node with literal args, parent receipts and public validity guards; guarded reuse validates the full dependency state or abstains; Certified Callback Substitution skips the otherwise redundant model callback while executing through the normal tool interface and logging a certificate. HumanEval 98 tasks: Codex **90.82%** success in both conditions at **66.72k vs 47.02k tokens/task** (−29.54%); DeepSeek Harness **71.43→85.71%** while 96.28k→11.62k tokens/task (large combined harness changes, not pure bypass effect). On 257 MBPP tasks, full 13.17k vs no persistent reuse 18.03k (−26.91%); compared with retaining model callbacks 16.37k (−19.52%). But disabling graph execution yielded slightly **higher success** (95.33% vs full 93.77%); improvement is cost/quality tradeoff, not universal. Development/training authoring and selection costs separate, custom public-state adapters and extra guard CPU required; new semantic choices always fall back.

**A.L.I.C.E. compatibility and action:** This cannot be an autopilot for previously approved actions; action authorization is current-state-, purpose-, identity-, data-class-, time- and permission-version dependent. Guard should also bind Claim validity, changed evidence, Mission predecessor and revocation generations, idempotency and uncertain external effects. “The action is cached” can never grant approval or silently execute a one-time permission twice. No hardware change, no default harness rewrite. If a genuinely repeated, idempotent, authorized Mission operation incurs material measured inference/cost overhead, one focused A/B on that exact operation including full development and run cost may inform later optimization. **Future-only.**
