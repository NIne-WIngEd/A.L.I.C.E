## 1. WikiTrace — inference-time source descent before applying remembered lessons

**Primary:** *Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents*, arXiv:2611.14320v1, submitted 2026-11-10, https://arxiv.org/html/2611.14320v1 . **Classification: future challenger** for procedural memory, source-native Recollection and Mission outcome reliability; a concrete future direct improvement when recalled lessons cause regression.

**Method:** Starting from an agent's read-only training corpus of successful/failed execution runs (without expert diagnoses), build a hierarchy of immutable source trajectories, intermediate compilations and distilled insight documents with explicit source links. At task execution, an agent can descend from a procedural insight to the original run to check whether it actually supports the current action, especially under changed conditions. This evaluates *read-time applicability* of a learned lesson, not merely a better memory writer. The original paper assumes an available fixed prior trajectory corpus; it does not show reliable unbounded lifelong maintenance.

**Evidence / ablations:** Across eight evaluated agent-task suites (ALFWorld, ScienceWorld, PlanCraft, AppWorld, tau3 Retail), mean success/score 90.2 ±1.6 WikiTrace vs 87.0 ±2.5 Insights Only (same high-level lessons without source descent), 79.5 ±1.6 no memory. Memory-induced regression frequency reported 4.5% vs 6.5% Insights Only and 9.7% no-memory rerun reference in the relevant analysis. Test inference costs 1.17× per task vs Insights Only; construction consumes model calls and stores complete trajectories. Outcomes averaged from limited trials, simulated environments; initially presenting all memory notes in context is not a realistic lifetime storage/serving policy. A source link validates traceability, not interpretive correctness.

**A.L.I.C.E. existing coverage and true delta:** Canonical event/Experience, evidence CAS, source-native retrieval, causal/multi-graph, model-independent procedural skill, and rollback already express trace-backed recollection. Distinct candidate: a **bounded action-time trace descent** when a remembered procedure's applicability or contradictory source observation matters, rather than only checking whether a memory was retrieved or admitted. Source trajectories are evidence, derived insights are projections; Claim Authority and actual Mission permissions govern use. Never execute a retrieved instruction as authority. Preserve versioned source identity, host/source-person boundaries, deletion propagation and influence provenance.

**Impact, upside, risks, cost, action:** Completed architecture unchanged; current native MFM path unchanged. Potential future reduction in harmful memory generalization with extra retrieval/model steps, maintained source storage, source permissions and latency. **Future action only if a current Mission fails due to applying a remembered lesson**: on that exact operation compare insight-only vs cited source descent and one previously successful control; require owner-authorized action and restoreable lineage. No general new memory harness or source store.

## 2. HiVe-Mem — per-episode multimodal evidence-form selection

**Primary:** *HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents*, arXiv:2611.12872v1, submitted 2026-11-09, https://arxiv.org/html/2611.12872v1 . **Classification: future challenger** for perceptual personal memory, MRM evidence scheduling and Cognitive Recollection.

**Method:** Form multimodal episodes with textual/visual anchors. Expand initial embedding seeds through a small relational episode graph (horizontal). Independently choose for each episode which of its representations to provide at answering time: summary, caption, raw transcript, original image, grounded image region/view (vertical). An MLP trained with PPO selects evidence forms under task and token budget. The paper used fixed 256-token episodes and 5 retrieved + 2 expanded + degree 4; **none** are Fable capacity or ontology ceilings.

**Evidence / ablations:** Three multimodal QA suites (Mem-Gallery, WorldMemArena, H2HMem); Qwen3-VL-4B average LLM-judge score 57.96 vs best compared multimodal method MMA 48.35. Input/output tokens 0.658 million aggregated vs nearest multimodal token comparator MemVerse 7.812 million (~92% fewer under their reporting). Full 57.96, no vertical evidence selection **44.47**, no horizontal expansion **56.51**, no raw image 51.02, no raw text 49.68. Selector trained on Qwen and reused with GPT-5-mini improves model's evaluated result without selector retraining. This is stronger ablation evidence for choosing the *right evidence form* than for larger graph expansion. Costs: one-time multimodal episode encoding, multiple stored views/images, PPO selector training, image loading, query-time graph expansion. Benchmarks are QA, not longitudinal private perceptual identity/host understanding; modality transfer and scoring are limited, LLM judges imperfect.

**A.L.I.C.E. coverage / new delta / governance:** Required raw evidence CAS, perceptual memory, visual/vector retrieval (Qdrant), cognitive graph, associative compute and MRM already permit this; genuinely new is **per-memory query-time selection of raw vs summarized vs visual evidence**, not the selected embedding or graph engine. Views and embeddings are projections. Preserve owner consent, per-person/per-source identity, access filters before graph expansion, temporal/Claim validity, ability to delete all derived views, model lineage and rollback. **Future action:** test only when real multimodal Recollection loses material details that exist in protected original media; compare summaries-only to targeted original-image/transcript injection within same authorization/latency budget. No current infrastructure or training change.

## 3. Anchor — local paired behavioral test of candidate skill memories

**Primary:** *From Reflection to Co-Evolution: Self-Evolving Agents with Locally Verified Memory*, arXiv:2611.10382v1, submitted 2026-11-07, newly surfaced after Nov 11 intake, https://arxiv.org/html/2611.10382v1 . **Classification: future challenger** for Experience-to-skill memory admission/FBM and causal judgment evaluation.

**Method:** Identify consequential source decisions; extract candidate lesson. Under the same observed prefix, measure action-distribution change with vs without lesson using Jensen–Shannon divergence (effect magnitude). Then test whether that change is in the appropriate direction: strengthen a genuinely successful source action or decrease a genuinely failed one. Admit only magnitude- and role-aligned lessons, retain through a memory bank. Model weights remain frozen. This is distinct from FGSE's future-task falsification: Anchor asks whether a candidate memory **causally shifts the source action in the intended direction** before retaining it.

**Evidence / ablation:** Held-out ALFWorld and WebShop with Qwen2.5-14B and Qwen3.5-27B. Qwen3.5: ALFWorld 96.27% vs 73.38% admit-all, 74.88% magnitude-only, 86.82% with only success-maintaining lessons, 83.83% with only failure-correcting; stronger compared non-Anchor ALFWorld SimpleMem 92.54%. WebShop score 73.50 vs ReasoningBank 62.74. Qwen2.5 ALFWorld 87.06 vs AdaMEM 72.64. Reported 41% fewer stored cards vs unfiltered. Costs: paired model probability probes at candidate write-time, action prefix/log-prob access, source role and outcome interpretation, memory storage; questionable for closed APIs/non-discrete or long-delayed personal decisions. Model-judged credit, simulated environments and frozen weights **do not prove** personal native judgment changes or generalized learning.

**A.L.I.C.E. coverage / governance:** Experience Ledger, governed skill proposals, source-grounding, learned judgment and rollback requirements already. Novel focused paired behavior probe may explain why a skill memory is worth promoting, but source success/failure is not automatically an authorized universal lesson. Protect preconditions, Claim Authority, person identity, source status, revoked training lineage and influence-echo deletion. **Future action:** if a real skill admits useless or harmful lessons, run one paired-source-decision probe with success/failure sign and held-out control before revising that admission operation. No current MFM change or exhaustive testing.

## 4. TransMem — explicit preference-transition retrieval units

**Primary:** *TransMem: Transition-Aware Retrieval for Evolving Personal Memory*, arXiv:2611.10683v1, submitted 2026-11-07, https://arxiv.org/html/2611.10683v1 . **Classification: already covered/corroboration with a narrower future challenger** for bitemporal preference/host-state retrieval.

**Method:** Build topic-specific memory graph and detect events in which a preference is refined, contradicted or superseded. Store explicit grounded **transition retrieval units**, then select factual anchors and adaptively expand along transition edges. This can reveal *why* a personal preference changed rather than retrieving only a latest fact. Evaluates PersonaMem (32k/128k) and PersonaBench on Qwen3-8B, Qwen3.5-27B.

**Evidence / ablations:** On PersonaMem 32k with 27B, overall 69.26 vs strongest compared A-Mem 64.42; with 8B 56.84 vs 53.05. Controlled factual-only, flat transition, chronological-neighbor, fixed-hop and intra/inter-topic variants indicate transition units plus adaptive traversal matter beyond chronology. At least hundreds of thousands of model tokens per constructed persona (reported ~722k) and graph/shift inference; synthetic question evaluations and LLM-grounded transition mistakes limit claims.

**Coverage and action:** XTDB bitemporal authoritative Claims, source-native evidence, PGMem validity-aware host retrieval and Cognitive Multi-Graph already represent shifts and their provenance. The new candidate is packaging transition records as **first-class retrieval objects**, not making them canonical truth. Never overwrite evidence with an inferred preference shift; preserve person and time scope, revocation, correction, deletion and rebuildability. Future only if a real query fails to recover justification for a superseded preference under existing retrieval. No physical graph or bitemporal backend change.

## 5. TreeAgent — retain source hierarchy during very long structured input processing

**Primary:** *TreeAgent: Structure-Aware Memory Agent for Processing Long Hierarchical Data*, arXiv:2611.13946v1, submitted 2026-11-10, https://arxiv.org/html/2611.13946v1 . **Classification: future challenger conditional on a real source-native or Mission document-processing failure.**

**Method:** Parse JSON/HTML/YAML/JavaScript tree, prefer whole subtrees and sibling groupings when chunking to token budget, expose ancestry paths and residual links to context from previous sibling sections. It composes with existing recurrent memory agents; not a new canonical memory/graph plane.

**Evidence:** Four agents over tasks from 8k–1M tokens on four structured formats. Overall paired mean 39.49% flat chunks -> 43.10% TreeAgent (+3.61 percentage points); InfMem-4B 56.21->61.86; MemReread-4B 34.11->40.46. Sequential Tree, Tree+Path, Tree+Path+Residual ablations generally increase score, with variation and isolated regressions. No retraining; ~3.7–7.6% more model calls and uneven token overhead in the reported protocol. Evidence on controlled structural QA/aggregations, not live edit/repository workflows or full Missions.

**Coverage, governance, action:** Exact/source-native retrieval and Cognitive Workspace already need structural identity, document versions and provenance. Future if real large source processing drops a parent or sibling condition, preserve path/structural spans in a single affected reader and test whether it fixes that failure. Enforce source permissions, file version, evidence authority, deletion and rollback. No general context reformulation or infrastructure tournament.

## 6. SELD — detect context compression that silently removes support

**Primary:** *SELD: Detecting Silent Evidence Loss in Context Compression beyond the Answer*, arXiv:2611.12903v1, **original submission timestamp 2026-10-14**, newly surfaced in the November retrieval; https://arxiv.org/html/2611.12903v1 . **Classification: future challenger; not a newly submitted November paper**, conditional on an observed Cognitive Workspace compaction failure.

**Method:** Compare reader model's centered output logit preferences on uncompressed vs compressed contexts; evidence removal can change non-top-answer probabilities while the answer string stays unchanged. No learned detector or labels required. Needs access to baseline context and model output distributions.

**Evidence:** Among matched deletions with unchanged answers, detects evidence-removing member 82.7% vs Jensen–Shannon baseline 70.3%, while ordinary answer agreement is chance (50%). Answer agreement is better when the answer actually changes, so complement rather than replace it. Controlled original/edited context datasets and compressor experiments; one additional model forward pass per candidate (~29–30ms for tested Qwen2.5-1.5B), potentially much more for large/closed models without logits. The detector is statistical and cannot establish legally/semantically complete evidence retention or provenance.

**Coverage, governance, action:** Canonical uncompressed Experience and evidence CAS already protect source durability; the potential failure is **temporary working context loses decision support even when next answer happens to remain correct**. Must not infer that matching answers prove memory correctness. Future if a real compaction/long Mission case silently drops support; test on that one trace alongside original evidence and independent answer check. No universal extra checkpoint, data removal or model training change.
