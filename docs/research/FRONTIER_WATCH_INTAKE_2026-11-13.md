## 1. MemCredit — matched-state intervention-derived decision utility for memory selection

**Primary:** *MemCredit: From Relevance to Utility for Decision-Time Memory in Long-Horizon Web Agents*, arXiv:2611.15600, first submitted **2026-11-11**, https://arxiv.org/abs/2611.15600 . **Classification: future challenger** for Memory Resource Manager/Cognitive Recollection, a conditional **direct capability improvement** if observed decisions are harmed by similarity-based memory arbitration.

**Method/assumptions:** Estimate marginal utility of a memory conditional on a fixed agent policy, reconstructed environment decision state and already-present reference memories by matched *with-vs-without* interventions. Atomize interaction history, collect offline utility labels in replayable environments, fit an ExtraTrees regressor from state/relevance/age/source/entity/overlap/context descriptors, and at runtime choose positive-utility candidates greedily by predicted benefit per added token. Relevance retrieves candidates but does not set final priority; budget is a cap, not a target. No live environment intervention at inference. Up to O(M²) candidate-score evaluations as the selected set grows.

**Evidence/ablations:** Across **1,041** controlled interventions in 45 ALFWorld tasks **86.9%** have no measured behavioral effect, correlation of semantic relevance to utility ~**−0.011**, and mean utility rises to **0.176 in failure contexts vs 0.029 otherwise**. Across 134 ALFWorld evaluation tasks at **500 historical tokens**, reported SR@50 **86.57% vs BM25 65.67%**; WebShop on 200 tasks has score **0.612 vs 0.586** MemArbiter at ~**152 memory tokens/decision**, ~2.8× fewer than MemArbiter. Ablation utility-only with full features 84.33; without explicit state/failure indicators 86.57; interpolation relevance+utility 78.36; failure heuristic 70.15. Task-grouped learned-utility predictor is imperfect (Spearman **.220**, AUROC **.744**). Experimental environment deterministic, not live owner decisions; counterfactual worlds costly at data collection, empirical conditional credit is not a universal causal weight. Marginal scores can miss joint complements and cannot certify epistemic authority or safety.

**A.L.I.C.E. coverage/new delta/governance:** MRM, Recollection, authorized Experience, judgment evaluation and predictive scheduling already exist in the destination. *New:* intervention-labeled, **context-conditional utility-per-token** as a candidate arbitration signal rather than observational top-k credit; this addresses LEDGER's identifiability problem *only under actual controlled intervention*, not observational deployment logs. Utility cannot overrule mandatory source/Claim validity, current mission permissions, person separation or deletion. Every chosen view retains evidence provenance, time, and rollback/rebuild; negative or zero utility estimates never justify destroying evidence.

**Impact/action:** No completed/current construction change. When a real decision failure is attributable to choosing relevant but non-useful memories, compare existing MRM ranking to this scorer using that same frozen state/action policy and one matched control, then decide. Future-only; no general estimator rollout, counterfactual simulator, or infrastructure tournament.

## 2. MindMem — situated use of learned host/relationship state vs factual recall

**Primary:** *We Are What We Remember: Mental-State-Driven Memory for Long-Term Character Dialogue*, arXiv:2611.16223, first submitted **2026-11-12**, https://arxiv.org/html/2611.16223 . **Classification: future challenger** for host/person/relationship development and source-grounded active Recollection.

**Method:** An asynchronous consolidator maintains separate, episode-linked character, user and relationship state. At each conversational turn, a specialized trained mental-state reasoner selects active state, infers relevant intent/needs and seeks supporting episodes before the language generator speaks; SFT+GRPO improves the selection/action policy. Evaluation introduces *Situated Memory Realization* (SMR) alongside direct question answering (DQA) to measure whether the assistant acts on shared history naturally.

**Evidence/ablations:** MemReal-Bench derives synthetic task probes from month-long real-user interaction material and includes dyadic/group scenes. Reported **SMR 59.03% vs strongest memory comparison 34.84%** (+24.19 points), **DQA 82.58% vs 73.39%** (+9.19). SMR exceeds oracle target-memory injection (50.65%) in this protocol, suggesting use can be a distinct capability. Removing active state-guided recall lowers SMR from 59.03 to ~29.68; replacing the specialist with generic reasoner ~41.94; removing GRPO ~54.19. Scope limited by fictional/character persona tasks, synthetic probes, model judges, source construction, single selected generation path; apparent personal-need inference may be unsupported or intrusive. Extra state construction, specialist training, per-turn reasoning and retrieval add tokens/latency/storage; fixed 40-slot presentation is **not** Fable's ontology ceiling.

**A.L.I.C.E. coverage/new delta/governance:** Existing host, source-person, A.L.I.C.E.-self, relationship, event/episodic, graph/causal and native-verdict contracts already encompass the mechanism. New practical direction: test *situated, causally attributable use* of relationship evidence, not memory-quiz success or generated role-play. Model-conjectured motives remain inferences, cannot become host facts or authorize proactive action; source/counterparty visibility, Claim validity, revocation and rollback stay intact.

**Impact/action:** Future only. When native conditional personal judgment works, test one real consented relationship-specific choice under relevant/irrelevant state interventions with source links, outcome checks and provider-swap controls. No sixth memory model, independent external judge or immediate training diversion.

## 3. DISCERN — explicit clarification and earned abstention after evidence retrieval

**Primary:** *DISCERN: Preserve at Write, Resolve at Read for Persistent LLM-Agent Memory*, arXiv:2611.15729, first submitted **2026-11-11**, https://arxiv.org/abs/2611.15729 . **Classification: already covered/corroboration**, with a future **read-time decision contract challenger** if ambiguous names or absent evidence produce wrong committed answers.

**Method:** Immutable per-actor Experience events, derived bitemporal entity/episode graph, confusable entities linked rather than merged. A reader navigates profile→entity/session→fact→original transcript with read-only tools. Earned-answer and earned-abstain guards commit exactly one of answer / update / clarify / abstain based on evidence, name ambiguity and supersession. An LLM-extracted graph is a projection; terminal gate correctness depends on extracted graph completeness.

**Evidence/ablations:** Synthetic ENT-310 (310 questions; 210 answerable, 100 deliberately unanswerable) reports abstention **F1 .924 vs best compared ≤.802**, macro answer correctness **.861 vs .806**, entity resolution .800 vs ≤.40 (only 15 entity-resolution questions). Zero-tune LoCoMo macro .663 vs .638. Navigation-enabled ablation improves from ~.33 tools-off floor to ~.89 for reported task slice. Multiple LLM judges, synthetic enterprise names, modest difficult subset and extra navigation/model calls limit generality.

**A.L.I.C.E. coverage/new delta/governance:** Canonical event KurrentDB, authoritative XTDB Claims, separate graph projections, subject/host identity, bitemporal and exact-source access already provide the substrate. DISCERN must **not** relocate Claim Authority into its derived graph, treat generated state as canonical, or prescribe exactly four lifelong responses. The actionable delta is distinguishing *clarify an ambiguous identity* from *abstain after demonstrating absent evidence*, with source-citable answer outcomes.

**Impact/action:** No current failure. At the first demonstrated person/Claim resolution error where retrieved content was adequate, test whether a narrowly placed earned-clarification/abstention guard fixes it, with same graph/Claim/source contracts. No new storage or generic benchmarking.

## 4. PriorSplit — separate procedural parametric priors from contradictory observed visual evidence

**Primary:** *Prior-as-Skill: Remember Outside and Read Inside with On-Policy Self-Distillation for Self-Evolving VLM Agents*, arXiv:2611.15766, first submitted **2026-11-11**, https://arxiv.org/abs/2611.15766 . **Classification: future challenger** for multimodal perceptual/procedural memory and external-versus-parametric scheduling.

**Method:** Teacher full-frame OPSD trains the visual reader; typical step-order priors are simple counts outside model weights using posterior `(nXY+1)/(n+2)`. At read time detect if both named steps are visible: use observed frame order when present, otherwise fall back to counted external prior. No additional training beyond reference OPSD; avoids internally learned prior overriding contradicting keyframes (prior bleeding), assuming visibility detection is reliable and order-prior samples are relevant.

**Evidence/ablations:** Qwen3-VL-4B synthetic six-frame study: baseline OPSD **51.1% short/missing-window, 98.3% conflict-window**; parametric prior distillation **69.1% short but only 83.8% conflict** (−14.5 points). PriorSplit reported best missing-frame results without the conflict collapse across five models and seen web/cooking/egocentric tasks; high results depend on controlled step-order questions, not open-world perception. More counted prior storage and inference detection, but no added training over OPSD; false visibility and distribution shift still allow errors.

**A.L.I.C.E. coverage/new delta/governance:** Raw perceptual evidence, temporal episodes, learned procedural skills, parametric memory and MRM are already required. New concrete phenomenon is **parametric procedural prior bleeding against newer decisive primary observations**, providing a scheduling example in which source-native evidence should win over a habit. A remembered statistical prior is neither verified historical fact nor current authority. Keep full source, time, person and environment lineage, and deletion/undo of both external prior and affected weights.

**Impact/action:** Future-only. If a real visual/web Mission misorders changed workflow steps due to an internalized prior, pair missing/contradictory evidence on exactly that failure and check one gated external-prior routing choice. No new model, change to current training, or migration.

## 5. MIGRO — portable external evidence across different underlying LLM generations

**Primary:** *MIGRO: A Decoupled and Portable Long-Term Memory System for Language Models*, arXiv:2611.15315, first submitted **2026-11-11**, https://arxiv.org/html/2611.15315 . **Classification: already covered/corroboration**, with conditional **future challenger** for compact, transferable personal memory packaging.

**Method:** Exact evidence archive with compressed evidence-body storage, approximate shared memory-address embeddings, and a model-specific retrieval/host adapter. Replayable snapshots allow a memory state to be used by new model generations/architectures without re-extracting all histories; newer models can append experiences. Key principle is *exact historical evidence, approximate navigational addresses, query-time selection*, not parametric transfer.

**Evidence/ablations:** A demonstrated inherited-state sequence across 4B→8B→14B→32B reports LoCoMo ~55.52→60.37→62.33 as readers improve; heterogeneous Qwen/Ministral/Gemma readers also access inherited state. Ten-state report quotes **54.13** LoCoMo at **1.115 MB** retained state vs Mem0 **50.45** at **160.671 MB** under the author's accounting; other transfer claims concern reduced rebuilding work (~740 forwards avoided). Comparisons across models/retention formats and content-counting conventions are heterogeneous. Compressed state still requires evidence retention, query embedding and per-model adaptation, index/adapter storage, source/version guards and migration checks; no general secure deletion/multi-device/recovery certification. Do **not** generalize paper state-size claims into a universal Fable capacity ceiling.

**A.L.I.C.E. coverage/new delta/governance:** Exactly the Fable model-independent Experience, encrypted CAS, source-native retrieval, first-party lineage and private evolution/rollback destination. New engineering candidate: validate whether exact archive plus lossy navigation addresses can reduce **specific** repeated indexing/transfer work when replacing a feature/reader model, not replace CAS, Qdrant, Claim Authority, or native judgment. Personal adapters/weights remain separate evolution responsibility. Provenance, subject isolation, authorization, deletion/revocation lineage and reindex/rebuild remain mandatory.

**Impact/action:** Future only when actual model-swap, index-space or packaging cost materially blocks work; test one selected handoff across incompatible tokenization/embeddings with exact evidence identity and one revocation control. No current-stack competition.

## 6. Folio — exact-handle context folding without repeated LLM-written summaries

**Primary:** *Folio: Recoverable Multi-Resolution Context Folding for Long-Horizon Language Agents*, arXiv:2611.16627, first submitted **2026-11-12**, https://arxiv.org/abs/2611.16627 . **Classification: future challenger** for long-lived Mission Cognitive Workspace and context/runtime economics.

**Method:** Record L1 short agent-authored turn note, L2 per-tool runtime event manifest and L3 original source capture simultaneously, all bearing stable digest/offset handles. Programmatic folding chooses cheaper existing views for older context; bounded `scan` reads, source-native full-text `ctx` computation and durable `dossier` can recover exact historical items; a cache-economics trigger explicitly prices retained landing size. Does not mistake historical replay for re-running side-effecting tools.

**Evidence/ablations:** On **75 LOCA-bench tasks** with identical DeepSeek-V4-Pro backbone, solves **66 vs 54** for same runtime with ordinary model-written compaction; other external agents 49–59. About **2.4×** lower normalized context cost, median fold **0.6s vs 101s** summary compaction; removing outline increases cost **63%**. A narrow long coding-agent benchmark with specific cache prices and window assumptions, incomplete capture remains unrecoverable, model L1 note may be wrong; requires exact archived records and handle maintenance. Runtime cheap folds but additional storage/index/read-tool maintenance, cost depends on provider and mission.

**A.L.I.C.E. coverage/new delta/governance:** Experience evidence and Result capsules, source-native exact reads, Cognitive Workspace, Temporal mission history and ephemeral context already express this. New practical technique is a cheap *view-selection fold* using pre-existing immutable handles and explicit landing cost, not canonically compressing or deleting evidence. Respect source permissions for every refetch, revocation, provenance, live-versus-historical distinction, rollback/rebuildability.

**Impact/action:** Future conditional. Only if long Missions actually expose costly repeated compaction/evidence-loss, test one source-handle fold against affected existing compaction on one reproducible Mission; no speculative caching subsystem.

## 7. Continual-ARC — persistence, delayed skill retention and unseen transfer are different outcomes

**Primary:** *Continual-ARC: Measuring Skill Acquisition over a Working Lifetime*, arXiv:2611.14505, first submitted **2026-11-10**; revision v2 **2026-11-11**, https://arxiv.org/html/2611.14505 . **Classification: future evaluation challenger / already covered in principle**, notably causal native learning vs merely stored experiences.

**Method:** Task identities reappear with new instances after dormancy while new tasks arrive. Agents pay for demonstrations, wrong attempts and environment feedback. After stream stop, test both new instances of seen tasks and unseen tasks; compare memory/harness learners and weight-updated teacher-distilled models on a common feedback budget, with single/multi-user protocols.

**Evidence/limitations:** Persistence of unassisted frozen harnesses generally fails to beat simple cached demonstrations on delayed repeated tasks; no evaluated harness gains on unseen task identities. Teacher-assisted weight-trained student does show unseen-transfer gains. Harness failures include memory being written but not selected (one agent only ~40/154 relevant returning records). ARC pattern environments are not real personal life, teacher distillation compute and feedback not free, public held-out tasks challenge absolute novelty, and task-specific program induction behaves differently from general purpose memory. This is a useful negative control, not proof that Fable must store skills in weights or abandon external cognitive planes.

**A.L.I.C.E. coverage/new delta/governance:** Current Fable training/evaluation requirements already separate stored evidence, learned native judgment, action, verified outcomes, regression and identity. A future qualification refinement is one *delayed new-instance memory recall* plus one *unseen situation transfer* under the same spending and privacy/lineage constraints; never make the ARC task inventory a Fable ontology/scale cap. Model training and multi-user learning require authorized source rights, separate owners, deletion and rollback.

**Impact/action:** No intervention in MFM's current checkpoint path. Preserve lesson for future FloRA attribution and learning assessment when actual personal-state model exists; do not start exhaustive benchmark campaigns.
