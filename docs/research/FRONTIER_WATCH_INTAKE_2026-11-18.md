## 1. EvoDisco — learn which operation reorganizes memory, not just what to write
**Primary:** Liu et al., *EvoDisco: Strategy Discovery for Evolving Agent Memory*, arXiv:2611.22102v1, first submitted **Nov 17, 2026**; https://arxiv.org/html/2611.22102 .
**Classification:** future challenger — Lifecycle Curator, associative graph compute, MRM/recollection; not a current contract defect.

**Method:** A small learned policy takes memory-graph state plus recent task history and selects four semantic memory-edit operations: Abstract/consolidate, Refine/split, Bridge/link, Reframe/reorient reasoning path. Immediate fitness tests retrieval-utility gain against complexity; strategic outer feedback combines operator regret, prediction error and selection diversity. Uses one GPT-5-mini call to propose an edit at an evolution event, embedding computation and 2-layer 128-hidden MLP trained by REINFORCE. One-pass online memory evolution then frozen memory transfer across benchmark streams; policies are not a new authority source.
**Evidence/ablation:** ALFWorld online 77.7%, frozen transfer 88.6%; transfer 80.7% without outer feedback, 79.3% without inner, 82.1% without operator library, and 85.7% with only Abstract. Improvements over MemP reach +8.8 online/+12.9 transfer points on ALFWorld. Reported full ALFWorld wall time 21.6h vs MemRL 33.6h and no-memory 36.8h, but task success changes number of steps; this does not isolate curator overhead. Single GPT-5-mini backbone, four fixed operators, heuristic trigger, transfer source ALFWorld, simulated tasks; no real human lifelong or deletion test.
**A.L.I.C.E. coverage and new delta:** Dynamic episode/graph edits, provenance, associative retrieval, read-time curation, MRM/Lifecycle Curator are already part of complete Fable v1. New technique is policy adaptation over *the type of derived-topology edit* with delayed benefit, rather than a fixed curation rule. Any rewritten graph remains derived, versioned, rebuildable; underlying Experience and bitemporal Claims control truth. Host, source-person, self and relationship edges must not be merged by a learned operator. Correction/revocation/deletion must invalidate/rebuild descendants and permit rollback.
**Upside/cost/action:** Potential higher transferable recollection with lower memory clutter; extra semantic edit calls, embedding/graph computations and training/policy state. Moderate benchmark evidence, no personal-memory proof. **Future only:** if a real curator suffers an operator-selection or stale topology defect, test one traceable relation repair against no edit and static edit; do not create graph/backend tournament, ontology/model count ceiling or MFM gate.

## 2. When Agent Skills Go Stale — selective content-level maintenance after environment change
**Primary:** Akgül et al., *When Agent Skills Go Stale: Runtime Behavior and Selective Maintenance in Evolving Environments*, arXiv:2611.22525v1, **Nov 17, 2026**; https://arxiv.org/html/2611.22525 .
**Classification:** future challenger; stronger mechanistic follow-up to previously tracked **Experience Rot** (Nov 16), not a re-announcement of that result.

**Method:** Distinguishes procedures that retain how to discover current environment values from cache-heavy skills that freeze previously resolved fields/commands. Before environmental change, capture cheap deterministic checks from verified successful executions. After change, replay those checks without LLM calls, compare current observations with stored expectations, identify conflicts with saved skill content, repair and validate locally, or rebuild if local repair cannot be verified. No advance changelog or change-description oracle.
**Evidence/ablation:** Paired W0/W1 experiments with two models on TerminalBench-2, historical tax forms, AppWorld and ScienceWorld. For a stronger model on TB-2, old cached skills change task score from 0.895 no-skill to 0.781 with stale skill (−11.4pp), and cost savings shrink. On IRS forms, 0.856 no-skill vs 0.731 stale (−12.5pp). ScienceWorld stale score 0.870 vs no-skill 1.000, while execution cost rises ~38.9%. Some model/benchmark settings still benefit from stale skills: direction is conditional, not a universal ban. Selective repair produces up to +67pp tax-field accuracy and −37% ScienceWorld steps relative to reusing stale state. Amortization versus reverting to no-skill occurs after roughly 21–42 uses in the tax form setting; four engineered environment transitions/two models constrain external validity.
**A.L.I.C.E. coverage/new delta:** A.L.I.C.E. has source-native/live reads, Mission outcome verification, procedural skills, Experience, Temporal, corrections and rollback; Experience Rot already motivated readback of consequential postconditions. Novel delta is **selective proactive skill-state check/repair tied to validated execution evidence** without mandatory LLM calls or expensive retest of all workflows. Skills are non-authoritative advice; tool permissions/owner policy cannot be conferred by past execution. Capture exact tool version/environment evidence, annotate repaired derivation, retire/rebuild affected learned procedures, prevent revoked source from reseeding skills.
**Upside/cost/action:** Potential cheap durable procedural reliability; checks require owner permission and may trigger side effects if not carefully isolated. Maintenance cost may not amortize for rare skills; old checks can be incomplete. **Future only:** for a documented real stale skill or changed API, validate one safe side-effect-free predicate, repair only affected state, execute with independent postcondition. Do not blanket-verify all APIs or reopen workflow transport.

## 3. RegimeCouncil — local-versus-pooled feedback on whether memory helps
**Primary:** Kang et al., *RegimeCouncil: Paired-Evidence Routing for Memory Conflict Governance in LLM Agents*, arXiv:2611.22113v1, **Nov 17, 2026**; https://arxiv.org/html/2611.22113 .
**Classification:** future challenger — Memory Resource Manager/recall influence calibration, not Claim Authority.

**Method:** Paired counterfactual with-memory versus no-memory answer evidence. A Local Advisor learns whether a specific fact's memory is helpful; Global Advisor pools recent outcome trends across facts; Meta Governor defaults local to avoid cross-person interference, allows pooled policy when recent gains are demonstrably positive. Online routing after delayed feedback with no LLM retraining. This is use-time suppression, not updating bitemporal truth.
**Evidence/ablation:** LongMemEval update streams plus real-world historical drift TempLAMA/TAQA; Qwen3-30B-A3B, GPT-4o. On primary disagreement slice gain +5.2–7.3pp over best fixed Local/Global advisor; for one 352-episode stream full accuracy Qwen 70.2 vs 67.9 (+2.3pp), GPT4o 73.3 vs 71.3 (+2.0pp). Across paired schedules bootstrap intervals mostly positive; remove Global −2.0 to −2.3pp, remove Local −3.7 to −6.0pp, remove Meta −6.5 to −6.8pp. Improvement on narrow disagreement slice larger than on all queries. Requires paired outcome signal and delayed feedback/oracle; may not exist for real irreversible personal decisions.
**A.L.I.C.E. coverage/new delta:** Already has bitemporal Claim Authority, validity-aware host/person state, memory-use calibration and correction. Novel option is adaptive **scope of learned retrieval influence** during delayed invalidation without treating one error as evidence all memories are false. No learned advice may supersede XTDB canonical state, permissions, source/person boundaries, or deletion status. Recorded feedback must retain source and timeline and be replayable on rollback.
**Cost/action:** Two small advisor states, recency windows and occasional paired tests, rather than retraining; weak evidence outside controlled QA and synthetic delay. **Future only:** if an actual drift case causes over-broad memory suppression or repeated stale recall, compare one fact-local vs source-scope fallback. No current routing change.

## 4. Soteria — verifiable Mission plans plus runtime enforcement and guided recovery
**Primary:** He et al., *Soteria: Formally Verified Planning with Runtime Enforcement for Safe LLM Agents*, arXiv:2611.17880, first posted **Nov 13, 2026**, newly surfaced at this intake; https://arxiv.org/html/2611.17880 .
**Classification:** future challenger — Mission Graph/durable workflows/permission enforcement, not a current architecture-invalidating result.

**Method:** LLM-assisted but *manually checked* conversion of policy documents/tool contracts into preconditions, postconditions and temporal/data-flow rules. Compose reusable procedure subplans as guarded transition systems; statically verify with Dafny for tool-preconditions, no dead ends and policy conformance; bounded repair iterations. Runtime SpecMonitor still blocks invalid calls even if planner returns partial proof; executor uses verified roadmap for recovery.
**Evidence/ablation:** 207 tasks, three benchmarks (tau2-Airline/Retail, Toolathlon), four models, 100% **against the provided formalized specifications**, zero measured violations. Baselines at most 93% conformance. Overall conformance-gated success 1.7x best baseline on average, model-by-task differences. Airline ablation GPT-5.4-mini flat plan 44% success/74% conformance, +verification 46/80, +subplans 50/80, full monitor 60/100; similar on Gemini 3 Flash. Airline cost GPT-5.4-mini $0.125 vs no-guardrail $0.031 per task (~4x); compare with full planning baseline for context. Hand-authorized specs may omit real requirements; formal verification assumes postconditions accurately model tool side-effects; runtime SpecMonitor cannot certify unmodeled environment truth.
**A.L.I.C.E. coverage/delta:** Already has Mission Graph, Temporal, owner-controlled permissions, tool action governance, outcome readback and Experience. New candidate is *pre-execution static plan compliance with recovery path*, not merely blocking unsafe calls one-by-one. Cannot let model-proposed policy become owner authority: approved tool contracts/specs must come from legitimate domain/owner governance, be source-linked, versioned and auditable. Execution state and corrections remain Experience, Claim authority remains separate; rollback/rebuild permitted. Verification is not universal safety proof.
**Action/cost:** Human specification effort, per-Mission verifier/planner time and API cost; strong controlled policy-check evidence, limited applicability of formalized benchmarks. **Future only**: if a real high-impact Mission fails due to missing precondition or blocked-action dead-end, formalize exactly that contract and test plan before use. Do not require formal DSL for all Missions or substitute Temporal.

## 5. RSI-Prime — training the autonomous model trainer on good decisions
**Primary:** Zheng et al., *RSI-Prime: Training Models to Train Models*, arXiv:2611.23138v1, **Nov 17, 2026**; https://arxiv.org/html/2611.23138 .
**Classification:** future challenger for FBM/Builder trace learning; not an immediate FBM recipe replacement.

**Method:** 350 complete model-training trajectories across seven task families. Identify decision episodes spanning multiple messages/commands, annotate quality of *decisions* rather than merely failures of individual tool calls, mask poor decision spans in SFT while preserving contextual trajectories. 75.48% of supervised tokens remain. Critical distinction from prior generic procedural credit: learn the builder's experiment choices from model-training histories.
**Evidence/ablation:** GLM-5.3 on PostTrainBench v1.2, six target-model training tasks, Qwen3-4B-Base target, one H100 and cumulative 10h/task. Original overall 36.56; Full SFT 45.61; decision-quality SFT 48.24 (+31.95% **relative** vs original, +2.63pp vs full); tool-failure masking 45.12, step masking 43.21 with similar retained token count. Training–test overlap in HumanEval-related data explicitly acknowledged; small, expensive evaluation, annotation fidelity and external personal-foundation transfer unestablished.
**A.L.I.C.E. coverage/delta:** FBM already stores attempted builds, causes, corrections, source/compute/lineage/qualification receipts. New candidate is decision-level filtering of these traces when training FBM. Training targets cannot use private host data in shared builder; evaluation results and model/dataset lineage must be independently attested, with rollback and sanitation after revocation. Do not confuse improving a general model-posttraining agent with proving autonomous construction of the whole Fable foundation.
**Cost/action:** LLM annotation and supervised training, multiple H100-hour experiments plus data curation; promising but not causal proof for current FBM state. **Future only:** once actual FBM trace training needs an admissibility/negative-example decision, compare the effect of retaining full execution context but masking one demonstrably wrong decision; no broad benchmark or new builder-model training gate.

## 6. Language Models Can Rewrite Their Own Weights — gradient-free weight repair by a sufficiently capable model
**Primary:** Fan et al., *Language Models Can Rewrite Their Own Weights*, arXiv:2611.21885, dated **Nov 16, 2026** (newly surfaced in Nov 17 papers); https://arxiv.org/html/2611.21885 .
**Classification:** speculative future challenger for governed personal-model evolution, not native personal learning and not MFM repair.

**Method:** A 27B model inspects graded answer traces and hidden states, proposes short code editing weights, tests paired candidate vs original, submits only if practice tests improve, with no gradients/optimizer. One edit removes 5% of a hidden-state direction implicated in looping; another identifies an anomalous weight matrix in a deliberately corrupted model and clips outliers. Edits persist with no serving-time penalty but self-edit sessions take hours and GPU memory. Different sessions begin at original base rather than an indefinitely validated continuous upgrade.
**Evidence/ablation:** In fixed pre-registered evaluation 490 held-out math questions with 8 samples, a submitted edit improves absolute accuracy by ~6.6pp; other edits significant but some attempted edits fail. 2B makes no edit; 4B/9B self-edits destroy their capability or are withdrawn. For deliberate corrupted 27B vision-capable weights, six image benchmarks 7% to 70%, 83% of undamaged model ability. Improvement often repairs repetitive generation or artificial corruption, **not** acquired person-specific judgment from lived experience. Limited models/tasks, no deletion/identity influence evidence.
**A.L.I.C.E. coverage/delta:** A.L.I.C.E. already requires model generation lineage, owner-governed personal model evolution, capability retention and rollback. New mechanism is a possible direct self-diagnostic repair of a narrow learned defect. A weight patch cannot become an authority, cannot obscure whose data influenced it, and must be subject to content-addressed generations, tests, owner permission, deletion/revocation contamination checks, quarantine and rollback.
**Cost/action:** Expensive 27B local/private GPU, introspection sandbox, potential catastrophic capability loss; interesting proof of possibility not deployment-ready. **Future only**: retain as targeted repair concept if a specific model failure is localized to a parameter pathology. Do not graft self-weight-edit into current 4B-class MFM or N0/FBM.

## Additional screened — not an actionable new plane

**LMLineage:** Hou et al., *Content Lineage and Context Governance for LLM Agents*, arXiv:2611.22511, Nov 17; https://arxiv.org/html/2611.22511 . **Already covered/corroboration** (with narrower future context-compaction diagnostic). Embedding-window sentence-to-input *support* attribution plus conservative micro-compaction of drifted documents, preserving user instructions. Gold set 71 Chinese QA sentences, 90 turns of other sessions; fine-grained source attribution roughly 0.55–0.63 in 3–40 turn trials; 0 wrong compactions in 10 replay sessions but only 30% drift recall. One setup ~1s/turn GPU; a separate gold attribution configuration ~12s/turn; CPU gate often skips large contexts. No controlled end-to-end compaction benefit yet, patent application noted. **Critical caution:** similarity/support is *not* causal influence provenance; prior Cited but Unused warns apparent source support can misattribute parametric influence. Do not use to drive deletion key dependencies, Claim Authority or authorization. If actual Cognitive Workspace compaction drops a protected instruction, preserve verbatim instruction and inspect missing evidence, not deploy this similarity score as a deletion arbiter.
