## 1. Some Memories Must Fade — selective parametric persistence, reinforcement and abstention

**Primary:** Vijayvargiya and Lokesh, *Some Memories Must Fade: Persistence and Decay of User Memories in Model Parameters*, arXiv:2611.25235v1, **submitted November 18, 2026**, https://arxiv.org/html/2611.25235 . **Classification:** **future challenger** for MRM → governed parametric-personal-memory update policy; not a present MFM repair and **not machine unlearning**.

**Actual method:** Frozen Qwen3-1.7B plus independent memory and retrieval LoRA adapters. Sparse `k`-hot routed subsets of the memory adapter's frozen-A/trainable-B rank columns act as memory addresses (demonstrated R=32, k=2, 496 combinations). Each rank has exponential weight decay controlled by a lifespan; a separate retrieval adapter is trained to say “Unknown” when a trace is too weak. A 2M-parameter controller receives event embedding, historical GRU state and rank ages/norms/prediction signals, and predicts a write gate, SGD depth (0–150 steps) and one of five lifespans. Trained by metadata-oracle imitation with state-aware DAgger; optional PPO. Identical event classes can demand different lifetimes for different users.

**Experiments/ablation:** 909 synthetic multi-year user trajectories (700–1,500 days) generated with dense validity annotations; final evaluation **15 held-out users / 4,584 lifecycle queries**, class-balanced recall-plus-expiry scoring. Fully learned router/controller **0.56** versus metadata oracle **0.65**, compute-matched managed RAG **0.50**, strongest conventional CL/PCGrad **0.42**; perfect routing reaches **0.60**. PCGrad's valid retrieval is **0.82** but its post-expiry abstention **0.00** in their separate test. Replacing state-aware DAgger labels with fixed metadata depths reduces 0.56→0.49; uniform decay cannot separate facts; shared rank columns cause write interference and overwrite each other's decay assignment. Results concern templated facts and expiry, not natural free-form judgment or reliable exact erasure.

**Already covered vs new:** Canonical bitemporal validity, source authority, external vs parametric/activation scheduling, owner-governed personal-model evolution and rollback already required. New concrete candidate is **learning the native parametric write strength and duration from an individual longitudinal trajectory, with calibrated expiry/abstention**. A rank-32 or 496-slot experimental implementation is not a permanent Fable bound.

**Rights/governance/scale:** Parametric decay is **not** owner-requested deletion: adapters, backups, descendant weights, synthetic data, caches and influence echoes still need explicit lineage-aware revoke/rebuild/unlearn testing. Never use decaying learned memory to suppress currently authoritative Claims or original evidence. Source subject, permission, correction, valid time and adapter generations must stay separable. Runtime cost includes dozens/hundreds of SGD steps per stored fact and stateful routing; frozen foundation/controller training and calibration are nontrivial, though small online controller inference. Synthetic templated test, only 15 held-out user streams and shared-rank collision cap evidence strength at **moderate for isolated lifecycle mechanics, low for real lifelong personal cognition**.

**Action:** Future-only: if an *actual* personal adapter persistently recalls expired preferences or cannot balance retention/abstention, compare an owner-authorized lifespan/depth policy with existing governed MRM path on that failure. Never use this to replace MFM's currently selected checkpoint-10 continuation or deletion gates.

## 2. EgoWitness / EgoClue — object-instance, observer and location/time binding in visual history

**Primary:** Fang et al., *EgoWitness: Benchmarking Instance-Level Spatial Memory and Reasoning in Egocentric Video Streams*, arXiv:2611.25849v1, **submitted November 19, 2026**, https://arxiv.org/html/2611.25849 . **Classification:** **future challenger** for personal perceptual/autobiographical-memory evaluation and action-time evidence verification; **already covered** in logical planes.

**Actual method:** 8,453 human-reviewed questions over roughly 324 hours of recordings. Instances are linked to human-reviewed masks/tracks, room timelines, time, object category, source wearer and visual reference. Crucially distinguish **observer location**, **object location** and **registered landmark location**, and distinguish object identity from category. EgoClue trains a Qwen3.5-4B retrieval controller with SFT then GRPO (answer/evidence/format rewards), choosing Memory (candidate intervals), Video/Image (visual instance inspection), Topology (room paths) and Timeline (durations/counts). Video begins at 1 FPS and refines selected intervals. Source observations, not generated summaries, are evidence.

**Experiments/ablation:** Across 12 direct VLMs, best open-weight accuracy **46.97%**, no direct model above **35%** on who saw an object last; strongest proprietary direct VLM **73.56%**. Trained controller on 1,320 held-out week-long questions improves **23.64%→72.65%**. Optional external answer synthesis from the same evidence trace reaches **74.85%**, not a native 4B claim. 787 shorter cross-environment questions withheld from training. Tool-removal experiments show that direct video, timeline and topology are not interchangeable; the benchmark includes evidence correctness as well as answer correctness. It is not a lifespan-scale personal biography test and its extensively reviewed annotations are not a realistically free ingestion process.

**Already/new:** Fable already needs multimodal source custody, entity identity, distinct host/source-person/others, temporal graph, exact video reads and perceptual retrieval. New, unusually discriminating **identity–observer–space–time evaluation** separates “where it was” from “where the camera user stood” and “who last saw *that instance*.” Useful diagnostic if near-duplicate object/person sightings contaminate personal recollection.

**Governance/cost/strength/action:** Permission-bound audiovisual evidence and identity consent; observation wearer must not be silently equated to host; source-timestamp and room/visual graph links must be invalidated on deletion and recoverable on rollback. Heavy video processing, mask tracking, multimodal specialist calls and training data; more expensive than text-only episodes. Evidence **moderate** for agent tool-mediated spatial memory, **low** for untethered long-term deployment. **Action:** Future-only: preserve one source-grounded instance-vs-category / observer-vs-object-location scenario when perceptual source identity is actually implemented. Do not adopt the five-tool ontology as fixed or open a new graph/vector tournament.

## 3. MemFolder — reduce retrieved record count *and* per-record length without discarding original evidence

**Primary:** Liu et al., *MemFolder: Structure-Guided Memory Folding for Efficient Agent Memory Management*, arXiv:2611.26427v1, **submitted November 19, 2026**, https://arxiv.org/html/2611.26427 . **Classification:** **future challenger** for Lifecycle Curator / Recollection efficiency, with **already-covered** derived evidence grouping.

**Actual method:** RecordFolder clusters related external memory records using entity grounding, complementary anchor selection, semantic affinity, chronological non-branching chains and chronological LLM consolidation. ContextFolder then produces *shorter encodings within the same groups*, having a planner extract important atomic facts/dates/negations and a blind verifier reconstruct those facts from the compressed text. They optimize two independent quantities: retrieval-unit count and token length of each unit. Originals remain available as distinct sources in Fable, not destructively replaced by derived folded text.

**Experiments/ablation:** Evaluated LoCoMo, LongMemEval, PersonaMem and two M3-Bench multimodal variants with Mem0/MemOS frameworks; three runs, GPT-4o-mini used in consolidation, two A100-80GB GPUs for experiments. On Mem0, **50% fewer records** retains **99.0%** average original performance, versus strongest alternative **97.1%**; at 70% reduction, **96.6%** vs **93.3%**. Mean retrieval speedups **1.41–1.86×** at 50% retention, **1.88–5.34×** at 30%. After 50% record-count reduction, ContextFolder cuts tokens per record by about **40.3% (LoCoMo), 37.9% (LongMemEval)**. Full anchor/affinity ablations show cosine similarity has largest impact (minus 3.4 pp without it); removal of planner or verifier worsens recovery/accuracy. Recall and compression are not equivalent to authority correctness, and the up-front construction/model-call cost is not a demonstrated net win at every scale.

**Already/new:** Existing derived episode consolidation, graph/entity grouping, canonical evidence, exact-source reads, MRM and Recollection. New candidate is **a two-dimensional cost policy**: fewer retrieval groups alone can lengthen read context; constrain both count and length and test recoverability of exact source facts. Do not turn the benchmark compression percentages into system limits.

**Governance/cost/action:** Preserve original record IDs, source entity vs host scope, corrections, valid-time distinctions, contradictory facts, source permissions, audit/evidence dependency and deterministic invalidation of compressed descendants; verifier success is not Claim Authority. Ingestion/consolidation cost includes entity LLM, clustering, compressor/verifier passes and index rebuilds, offset by lower index/read-time latency. Evidence **moderate for benchmark retrieval efficiency, low for actual private Fable workloads**. **Action:** Future-only if real large-history lookup/prefill cost is measured to block performance; compare focused grouping+verified encoding against the selected retrieval path on that case. No Qdrant/graph engine change or compression project for its own sake.

## 4. Forget Freely, Grep Later / GrepMem — direct history grep as a lossless compaction fallback

**Primary:** Yang, Shi and Zhao, *Forget Freely, Grep Later: Lossless, Index-Free Memory for Long-Horizon LLM Agents*, arXiv:2611.25123v1, **submitted November 18, 2026**, https://arxiv.org/html/2611.25123 . **Classification:** **already covered/corroboration** of exact/source-native memory plus a **future harness tool improvement**.

**Actual method:** Ordinary lossy context compaction plus append-only complete interaction/trajectory log; the agent can call `grep_history` to recover omitted details. Unlike richer RAG/graph memories, its retrieval path requires neither an embedding index nor up-front memory-authoring. Qwen3.5-9B was separately GRPO-trained under each of five context policies, fixed 32,768 context, common 4,000-episode training mix and tool/turn budgets.

**Evidence/ablations:** Five tasks spanning BrowseComp-style three-question research, AMA recorded trajectories and ContextBench streams; after RL, **66.4%** average with GrepMem vs **56.3%** for the tested MemGPT policy and ~**30%** for summarization/masking; exact ContextBench KV **97.4%** and Log Triage **95.3%**. GrepMem BCP-Multi **46.9%** vs SUPO **38.1%**. Where all methods already share native access to a recorded trajectory, improvements are smaller. After-RL token-cost Pareto comparisons are reported, but local grep/search and retention costs still exist; these are heterogeneous agent benchmarks and an RL-trained harness comparison, not general native memory formation.

**Already/new:** Fable already mandates immutable raw Experience/source-native reads alongside lossy working context. Genuinely useful implementation idea is **an explicit simple exact-history query action** when a state summary was insufficient; avoiding an index for this action is not evidence against the required graph/vector/claim planes.

**Governance/cost/action:** A grep result is *original evidence*, not accepted truth or permission. Search must be host-scoped, source-scoped, deletion-aware and avoid recovering revoked content from logs, backups, snippets or cache. Complete logs increase retention/storage and access-risk; grep may scan many bytes (cheap sometimes, poor for multimodal semantics). Evidence **moderate** for recovering exact text omitted by compaction, **weak** for complete lifelong personal memory. **Action:** No architectural work now. For an actual Cognitive Workspace compaction failure, first expose a narrowly authorized exact-history search over existing evidence custody; measure whether it repairs the case without new model training.

## 5. LATER — latent memory of observed physical transitions, read by candidate action

**Primary:** Zhou et al., *LATER: Learning Action-Conditioned Temporal Evidence Retrieval for Predictive World Models*, arXiv:2611.25671v1, **submitted November 19, 2026**, https://arxiv.org/html/2611.25671 . **Classification:** **future challenger** for world/environment memory and model-based Mission planning, not a current Fable capability defect.

**Actual method:** A CF-JEPA-derived predictive world model keeps recent latent tokens plus separate completed-transition latent banks, with multi-cut writer supervision. A low-rank, zero-initialized gated residual and response bridge read **fixed historical observations conditioned on the current candidate state and action** while predicting; hypothetical rollouts never overwrite the factual bank. The bridge correction is limited to an eight-dimensional output subspace in this experiment, which is not a limit on Fable's causal/world capability.

**Evidence/ablation:** On distracted two-stage PushT (early probe informs later unseen friction), terminal task success **15.5% reconstructed CF-JEPA→25.0% LATER** (paired CI for gain [3.0,16.0] pp). For held-out physical displacement readout, along-push MAE **23.70→17.08 mm** (27.9% reduction), 10-mm endpoint accuracy **17.3%→33.0%**. Persistent memory without bridge yields **16.0%** on distracted PushT, bridge with recent-only **19.0%**, both **25.0%**. Counterfactual intervention replacing the early physical experience with an opposite-friction history degrades MAE **17.08→34.15 mm** while changing only historical visual distractors leaves MAE ~16.76 mm. This specifically establishes dependence on prior *physical* experience in the controlled simulator, not merely temporal retrieval score.

**Already/new:** Fable already requires Environment/World and causal state, Experience trajectories, activation/working memory, action-result learning and governed Missions. New candidate is **action-conditioned read-only access to recorded transition history during multiple hypothetical rollouts**, separating observed world memory from imagined future state. This is more directly causal than generic embedding retrieval, but the paper only demonstrates small simulators/physical dynamics.

**Governance/cost/action:** Never let hypothetical forecast trajectories enter canonical Experience/Claim as observations. Bind executed-action/observed-effect provenance, device/sensor scope, authorized use and physical uncertainty, and invalidate derived latent states with revoked source/model generations; preserve rollback. Compute costs include perception, two learned banks and extra attention/bridge steps plus full world-model training; small fixed latent bank may not cover long-life physics or social causality. Evidence **moderate for action-conditioned short-horizon physical reasoning, low for general personal-agent world modeling**. **Action:** Future-only if a real mission/environment prediction failure shows earlier observed physical affordances being ignored. No new world-model training gate now.
