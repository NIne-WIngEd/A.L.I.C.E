## Why this is the final N0 package rather than another repair patch

The valid failure chain now isolates a specific boundary.

Jobs 575956, 575957 and 575958 progressively localized the Production operator failure to relation identity/order transfer rather than P1 execution or infrastructure.

Job 575962 moved the semantic problem ahead of Production P2 and showed the first broad schema matcher could not reach the required semantic fidelity.

Job 575966 repaired the known schema-format, factor-supervision and pair-interaction defects. It then reached perfect Production-core relation fitting while unseen relation and held-out factor semantics stayed substantially below gate.

That result rejects another trainable P2S matcher as the next semantic authority.

The package therefore removes that learned semantic bottleneck instead of changing its optimizer.

## Full-scale architecture

The package preserves every previously ratified N0 subsystem that has not been invalidated by evidence:

- the full `alice-n0-semantic-v0.2` semantic model;
- structured state;
- evidence graph and repaired endpoint semantics;
- heterogeneous cross-context fusion;
- adaptive multi-view latent pool;
- corrected P1 relational executor;
- ordered relation-program state;
- continuous relation hypotheses;
- Binder v2 adaptive exact sparse structural support;
- uncertainty surfaces;
- the original frozen native N0 final validation.

No smaller pilot model is substituted.

No previous full-scale subsystem is replaced by a convenience mock or reduced-width proxy.

## Semantic authority

The relation/factor semantic authority is now derived directly from the already-trained, ratified N0 semantic model.

It combines four frozen views:

1. the trained joint prompt/candidate preference scorer;
2. the trained semantic projection;
3. the trained semantic-to-rationale principle-alignment surface, including the rationale projection;
4. a parameter-free token evidence matcher.

The fourth view matters because the original N0 teacher objective explicitly trained semantic candidate representations against rationale representations. The closure package now uses that trained surface rather than leaving it idle.

There is no semantic-authority optimizer.

There is no learned P2S checkpoint.

There is no relation-identity table.

There is no factor-class head.

There is no candidate-count or hop-count parameter axis.

The authority components are normalized only after the runtime candidate set has been selected.

That matters because Production TRAIN receives only its six core relation candidates. Open-schema relations therefore cannot influence TRAIN by appearing in a normalization denominator.

Production DEV uses its complete runtime schema.

The original frozen final validation uses its own complete runtime schema.

## Ordered semantic programs

The operator still learns the aspects that actually require sequential execution.

At each recurrent step the relation decision contains:

`frozen semantic authority + remaining-evidence support + bounded ordering residual`.

The semantic authority answers what the supplied runtime relation means.

The remaining-evidence term makes consumed query evidence less available to later steps.

The recurrent residual can learn which already-recognized relation belongs at the current program position without becoming an unconstrained replacement semantic classifier.

The relation distribution stays continuous.

Exact structural sparsity begins only in Binder v2.

## Factor semantics

Role, traversal, direction, control and modifier identity use the same frozen semantic-authority principle.

The current factor bank is an operating semantic contract, not a parameter-topology ceiling.

The operator itself has no factor-count-dependent trainable class heads.

A future expanded factor schema can change the runtime/config operating point without requiring a fixed relation/factor identity table in the operator.

## P2A gate

The first stage is now P2A.

P2A is a zero-gradient qualification of the frozen semantic authority.

It reuses the existing P2S semantic-generalization gates rather than lowering them after failure.

If P2A does not pass, Production P2 is not authorized.

That outcome would mean the semantic deficiency lies below the operator: the ratified semantic base does not yet provide enough zero-shot schema semantics for closure.

In that case the correct next action is semantic-base localization, not another learned-head patch.

## Runtime-schema lineage

The Production and final authority caches are now bound to the exact preserved dynamic schema caches.

The package checks:
- the current relation-schema source hash against the preserved schema cache;
- the semantic checkpoint hash used by that schema cache;
- runtime relation-key order;
- Production curriculum/cache lineage;
- authority qualification lineage.

The final authority cache is a deterministic zero-gradient representation of the already-frozen final corpus and schema. It does not rebuild the final corpus, change any threshold, select a checkpoint, or authorize training.

## Full-scale versus current operating point

This package explicitly separates a qualified operating point from a capability ceiling.

The current:
- 640-dimensional semantic width;
- operator width;
- hidden-state depth;
- field counts;
- factor counts;
- P2/P3 training budgets;
- batch sizes;
- four-step training-time operator budget

are not declared permanent A.L.I.C.E. capability limits.

The recurrent operator has shared step weights, so its training budget does not create a learned hop-index parameter axis.

Runtime relation count remains dynamic.

Runtime relation identity has zero parameter axes.

If future evidence localizes an expressivity bottleneck after N0, relevant width/depth/schema capacity can expand. The present package does not forbid that.
