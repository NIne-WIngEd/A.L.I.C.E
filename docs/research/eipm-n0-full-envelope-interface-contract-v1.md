# N0 Full-Envelope Interface Contract v1

**Date:** 2026-09-21  
**Status:** static successor interface; no optimizer, gradient, GPU, TEST, or private identity authorization

This contract converts the retrospective audit into explicit module boundaries. It prevents a repaired local component from quietly reintroducing one of the closed assumptions.

## Semantic/operator foundation

The same semantic backbone encodes query text and runtime schema descriptions. The operator consumes multi-layer token states without detaching them. Relation count, factor-bank cardinality, type vocabulary size, and recurrent step count are runtime axes.

Relation/factor keys are metadata only.

The semantic/operator layer emits continuous relation/factor distributions, continuous state, uncertainty, STOP/UNKNOWN/CONTINUE events, and ordered token-evidence coverage. It does not produce exact structural support.

## Structured state

Keep permutation-safe set processing, confidence, missingness, provenance and temporal channels.

Do not let a learned integer field/provenance/role/temporal ID be the only semantic meaning of a runtime category.

A successor structured state consumes semantic descriptors for runtime types/provenance/temporal scope. Integer IDs may remain structural/cache indices.

## Evidence view and graph

Keep the evidence-specialist view and the dual-endpoint graph mechanics.

Remove the old dependency on one pooled frozen query vector and remove relation-ID embedding tables as semantic authority.

Edges may carry an integer index into the runtime relation schema. Meaning comes from the supplied runtime schema state and operator state.

## Fusion

Keep source-anchored multi-stream fusion. Exact parent/source channels remain valuable.

Checkpoint view IDs cannot be the only meaning of a view. A successor must be able to receive view descriptors and must be requalified after upstream representation changes.

## Latent pool

Keep competitive multi-slot evidence allocation and emergent slot semantics.

Step360 is not a permanently ratified final N0 parent. It is a useful initialization/comparison candidate.

## QSRE executor

Keep Production Core's dynamic relation schema, shared recurrent execution, continuous relation hypotheses, ordered evidence coverage, uncertainty and exact fallback.

Do not restore T1/T2 relation/role/operation ID embeddings as final semantic authority.

## Binder

Keep Binder v2 as the first exact structural sparsity boundary unless later evidence falsifies it.

Replace the final-layer-only query read with a multi-layer foundation state. Type masks remain exact structural constraints. Runtime type descriptions supply semantics upstream.

## Full-stack co-adaptation

Temporary freezes may still be used for causal isolation. They are not permanent.

The eventual public training workflow must contain a stage where all reopened semantic/structured/evidence/fusion/latent interfaces that require adaptation can co-adapt against the same full-envelope objective. A downstream module may remain frozen only when an explicit full-envelope sufficiency receipt justifies it.

## Public judgment readout

Candidate text is comparison material, not an independent judgment policy. The
final behavioral readout may inspect runtime candidate semantics, but every
candidate-specific scoring feature must interact with the current fused/latent
judgment state. A fixed learned projection bias or a standalone candidate-only
summary path may not rank candidates when the governed latent signal is absent.

This preserves the intended causal chain:

`source/evidence -> fusion relevance -> latent judgment state -> candidate comparison`

Candidate masking and permutation remain runtime structural mechanics. They do
not create candidate identity or a second hidden decision policy.
