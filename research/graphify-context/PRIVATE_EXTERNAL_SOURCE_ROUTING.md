# Private External-Source Routing Contract

Private sources are intentionally **not copied into this public research branch**.

The external layer includes sources such as:
- prior ChatGPT handoff/export PDFs;
- private or saved conversation artifacts;
- the A.L.I.C.E. comic/source package when it is outside Git;
- local execution transcripts not committed to Git;
- private project material and owner-only context.

## How Sol should retrieve them

Use the user's private ChatGPT Library / conversation-file retrieval surface with semantic queries targeted to the missing knowledge class.

Recommended search intents:

### Comic / destination behavior
Search for:
- `A.L.I.C.E comic continuous memory years decision history proactive specialist model replacement`
- `Alice comic destination capabilities continuity`

### Operational failure lessons
Search for:
- `A.L.I.C.E Magnolia udocker rayan-compute failure DNS egress PowerShell Kaggle JSON BOM`
- `A.L.I.C.E resolved errors workflow lessons continuation`

### EIPM frontier / competitor research
Search for:
- `A.L.I.C.E EIPM frontier research competitor models identity judgment architecture`
- `A.L.I.C.E personality model research personalized reward persona graph concept bottleneck`

### Chat continuation state
Search for:
- `A.L.I.C.E latest continuation N0 current state next action`
- `A.L.I.C.E last chat died continue from where stopped`

## Privacy rule

Do not commit Library IDs, private file contents, private conversation text, personal source payloads, or local private paths to this public branch.

## Verification rule

When a private source supplies a material operational or architectural claim, verify whether that claim was later promoted into Git. If it was, prefer the Git authority. If it was not, keep the source explicitly labeled private/chat-derived rather than silently treating it as canonical.
